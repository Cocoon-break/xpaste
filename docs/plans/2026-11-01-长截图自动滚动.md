# 长截图自动滚动（阶段 2）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 L 后程序自己平稳地往下滚、看着画面拼，到底自动完成；用户随时接手、空格暂停、回车提前完成；接不上时程序自己回滚重试。

**Architecture:** 节奏（每步滚多少、学比例、到底、恢复、不响应）是纯逻辑，放在 `xpaste_core::autoscroll`；拼接加“预期位移”提示与“当前位置”。平台层只提供发滚动事件、用户最近一次输入的时刻、指针位置与权限查询。`longshot.rs` 把三者接起来：发一步 → 等画面停下 → 把实际位移交给节奏 → 照它的决定做下一步。

**Tech Stack:** Rust；macOS CoreGraphics 事件（`CGEventCreateScrollWheelEvent2`、`CGEventSourceSecondsSinceLastEventType`）；Windows `SendInput`、低层鼠标键盘钩子；前端原生 TypeScript。

**Spec:** [长截图自动滚动设计](../specs/2026-11-01-长截图自动滚动-设计.md) 4.1、4.3、4.4 第 1 条，第 6 节阶段 2。基于分支 `feat/long-shot-auto`（PR #24，阶段 0、1），本分支 `feat/long-shot-autoscroll` 从它拉出；#24 合并后改基于 `main`。

## Global Constraints

- 只发滚动事件。不发键盘、不发点击，不移动用户的指针（设计反目标）。
- 不放松任何防接错的条件：预期位移只缩小查找范围，范围内仍按现有规则（精确比对的明显胜出、近似比对只有一个像样的位置）判定；范围内找不到再按原来的全范围规则找。
- 节奏数值（设计 4.3）：起步每步约选区高度的 1/3；连续接上就逐步加大，不超过 2/3；没接上步长减半并往回滚半步；连续 3 次恢复不了 → 暂停并提示“这里一直接不上（画面在变？），↩ 保留已拼好的部分”；连续 3 步发了滚动画面都没动 → 到底，按回车同样完成；开始后最初几步画面一直没动（从没成功动过）→ 转手动并提示“这个窗口不响应自动滚动，请自己滚动”。
- 用户接手：检测到不是自己发的滚动、按键或点击 → 暂停自动滚动，按手动方式拼接；停手 1 秒〔建议值〕后恢复。空格切换暂停与继续（长截图期间临时注册为全局快捷键，同回车、Esc，结束时注销）。
- 权限：macOS 没有辅助功能权限时不自动滚动，进入手动模式（现有行为）；Windows 不需要权限。设计 4.1 第 3 步的“前往授权”按钮不做：边框窗口不接收点击（点击要穿透给被截的应用），只在提示里写“授权辅助功能后可自动滚动”，授权入口沿用设置与提示条里已有的“前往授权”；在设计第 8 节记一笔。
- 不做设计 4.3 末条“可选的精确提示”（读系统辅助功能接口的滚动位置）：画面比对加预期位移已够用，读不到时也不影响功能；留到确有需要时。
- 提示文案（选区旁 `.tip`，后面固定跟“↩ 完成 Esc 取消”）：自动滚动中“自动滚动中，空格暂停”；暂停“已暂停，空格继续”；macOS 没权限“滚动选区里的内容 · 授权辅助功能后可自动滚动”；不响应“这个窗口不响应自动滚动，请自己滚动”；指针移出选区（只在滚动跟着指针走的平台上）“把指针移回选区继续”；其余沿用现有（没接上、一直接不上、到上限、选区较矮）。
- 日志不含画面内容、窗口标题、路径；可记步数、学到的比例、到底/不响应/恢复的次数。
- 运行应用只用 `make dev-isolated`；提交前 `make check`（含 Windows 交叉 clippy）。代码注释、日志、提交信息用中文，注释引用 M23 规则 13。
- Windows 代码在本机只能交叉编译；实机验证交给用户（验收记录标“待用户”）。

## Review Focus

- 自动滚动时用户只是移动指针（不滚、不点、不按键）：不算接手，自动滚动继续（Task 3、4 的平台实现按事件类型区分，Task 5 的 `auto_gate` 测试覆盖）。
- 页面本来就在底部（或选区不是可滚动内容）就按 L：最初几步不动 → 转手动提示“不响应”，不能当成“到底”立即完成（Task 2 的测试）。
- 滚动途中页面有动画或懒加载、某一步没接上：往回滚半步、步长减半，恢复后步长重新逐步变大，不会一直卡在最小步长（Task 2 的测试）。
- 预期位移偏了（比例学得不准、平滑滚动没停稳）：预期附近找不到时退回全范围规则，不会接到预期附近一个“像”的位置（Task 1 的测试）。
- 自动滚动中按空格暂停后，用户自己滚了一段再按空格：继续时以当前位置为起点，不把用户滚过的距离算进比例（Task 2、5 的测试）。

### Task 2: 自动滚动的节奏（纯逻辑）

**Files:**
- Create: `crates/xpaste-core/src/autoscroll.rs`（`lib.rs` 加 `pub mod autoscroll;`）

**Interfaces:**
- Produces:
  ```rust
  pub struct PacerCfg {
      /// 选区高度（物理像素）
      pub frame_h: usize,
      /// 滚动单位换算成像素的初始猜测（平台给：macOS 1 点 = scale 像素；Windows 120 = 一格，约 100 × scale 像素）
      pub px_per_unit: f64,
  }
  #[derive(Debug, Clone, Copy, PartialEq)]
  pub enum Act {
      /// 发这么多单位的滚动（正数往下，负数往回），并期望画面往下移动约 `expect_px` 像素（往回时为 0）
      Scroll { units: i32, expect_px: usize },
      /// 到底：按完成收尾
      Finish,
      /// 从没动过：转手动并提示“不响应”
      NoResponse,
      /// 连续 3 次恢复不了：暂停并提示“这里一直接不上”
      Stuck,
  }
  pub struct Pacer { /* 步长、比例、连续没动、连续恢复、是否动过 */ }
  impl Pacer {
      pub fn new(cfg: PacerCfg) -> Self;
      /// 第一步（或暂停、用户接手之后重新开始）
      pub fn start(&mut self) -> Act;
      /// 上一步发出后画面停下了：`moved` 为长图上位置的变化（像素，往回为负），`None` 为没接上
      pub fn settled(&mut self, moved: Option<i64>) -> Act;
      /// 日志用：学到的比例（像素 / 单位）
      pub fn px_per_unit(&self) -> f64;
  }
  ```
  数值：起步步长 = `frame_h / 3`；接上后步长 × 1.25，不超过 `frame_h * 2 / 3`；没接上时往回滚上一步的一半、步长减半（不小于 `frame_h / 12`）；比例按每步实际位移 / 单位做指数平均（新值权重 0.5），位移为 0 的步不更新比例。

- [ ] **Step 1: 写失败的测试**（模拟页面：`moved = units × 真实比例`，到底后为 0）：
  - `first_step_is_a_third_of_the_frame`：`frame_h 900`、`px_per_unit 2.0`，`start()` 为 `Scroll { units: 150, expect_px: 300 }`。
  - `learns_the_real_ratio`：真实比例 3.0（猜测 2.0），连续 4 步后 `px_per_unit()` 与 3.0 相差 < 0.1，且下一步 `expect_px` 与 `units × 3.0` 相差 < 5%。
  - `grows_to_two_thirds_and_no_more`：一直接上，若干步后 `expect_px` 不超过 600，且最后几步等于 600 附近。
  - `lost_backs_off_and_recovers`：一次 `settled(None)` 得到负的 `units`（上一步的一半），下一步步长为原来一半；之后连续接上，步长重新变大。
  - `three_failed_recoveries_are_stuck`：连续 3 次 `settled(None)` 后为 `Stuck`。
  - `bottom_finishes_after_three_still_steps`：先接上几步，再连续 3 次 `settled(Some(0))` → 第 3 次为 `Finish`，前两次仍是 `Scroll`。
  - `never_moved_is_no_response`：一开始就连续 3 次 `settled(Some(0))` → `NoResponse`（不是 `Finish`）。
  - `restart_keeps_ratio_not_user_distance`：学到比例后调用 `start()`，比例不变、步长回到起步值；`start()` 之前用户自己滚过的距离不会进入比例（`settled` 只接收自己那一步的位移）。
- [ ] **Step 2: 运行** `cargo test -p xpaste-core --lib autoscroll::`，期望编译失败。
- [ ] **Step 3: 实现** `autoscroll.rs`。
- [ ] **Step 4: 运行** 同上，期望通过；`cargo clippy -p xpaste-core --all-targets -- -D warnings`。
- [ ] **Step 5: 提交**“长截图：自动滚动的节奏（M23 规则 13）”。
