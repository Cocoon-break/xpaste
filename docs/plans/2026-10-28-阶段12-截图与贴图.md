# 阶段 12：截图与贴图 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按截图快捷键冻结屏幕，在每块显示器上的遮罩里框选或吸附窗口、做 7 种标注，然后复制（进入历史）、保存、识别文字或钉在屏幕上（贴图）；macOS 与 Windows 都支持。

**Architecture:** 平台层新增同步的冻结屏幕、窗口列表、屏幕录制权限接口（macOS `CGDisplayCreateImage` / `CGWindowListCopyWindowInfo`，Windows GDI `BitBlt` / `EnumWindows`）。应用层新模块 `shot.rs` 管理一次截图会话：启动时预建每屏一个隐藏的遮罩 webview（`shot-<i>`），按键时冻结、把原始 RGBA 以二进制响应交给遮罩页、页面画好后再上屏；遮罩页在 canvas 上按物理像素合成 PNG，以原始请求体回传给 `shot_finish`，由后端写剪切板（监听器照常入库）、存文件、OCR 或建贴图窗口（`pin-<n>`）。前端新增两个 Vite 入口 `shot.html`、`pin.html`，交互对照原型。

**Tech Stack:** Rust（tauri 2.12、tauri-nspanel、objc2 0.6 / objc2-core-graphics 0.3、windows 0.62、image）、`tauri-plugin-dialog`（新增，只用选择文件夹）、TypeScript + Vite 多入口（`node:test`）、CSS。

**Spec:** [docs/specs/2026-10-28-截图与录屏-设计.md](../specs/2026-10-28-截图与录屏-设计.md)（§2 目标、§4.1–4.5、§4.7 截图那几行、§4.8、§6 阶段 12）；交互以 [原型](../specs/2026-10-28-截图与录屏-原型.html) 为准；规格说明 v0.1.19 → v0.1.20（新增 M23，回写见 Task 8）。

- 日志不写剪切板内容、标题、文件路径、窗口标题、识别文字；只记尺寸、字节数、耗时、显示器个数、贴图序号。
- `Settings` 新字段带默认值，旧 JSON 能直接读出；同步 `changed_fields`、`src/api/types.ts`、`settings-form.ts` 与测试。不需要数据库迁移。
- 默认值：截图快捷键 `Alt+Shift+A`（空字符串表示不启用）；截图文件夹 macOS `~/Pictures/xPaste`、Windows“图片\xPaste”（设置里存空字符串表示默认）；保存截图时同时复制：开。
- 截图文件名 `截图 YYYY-MM-DD HH.MM.png`（本地时间，与 `capture.rs` 自动标题一致），重名依次加 ` 2`、` 3`。
- 遮罩：选区框与手柄用图片类型色 `--c-image`；蒙层 `rgb(0 0 0 / .46)`，与主题无关；工具栏、标签、提示按 M16 token 随主题；动效按 M20（键盘触发不加动画，`prefers-reduced-motion` 即时）。
- 遮罩键位（对照原型）：1 矩形、2 椭圆、3 箭头、4 画笔、5 马赛克、6 文字、7 序号；`Mod+Z` / `Shift+Mod+Z`；回车或双击复制；`Mod+S` 保存；O 识别文字；P 贴图；F 全屏；方向键移动 1 px，Shift + 方向键调整大小；Esc / 右键先取消选区，再退出。
- 标注参数：颜色 `#FF3B47 #FF9F1A #22C55E #0EA5E9 #8B5CF6 #FFFFFF`；线宽 2 / 4 / 7；字号 14 / 20 / 28；序号半径 11 / 14 / 18；马赛克笔宽 14 / 24 / 40、块 10 逻辑像素；Shift 约束为正方形 / 正圆 / 45°。
- 贴图：6 px 圆角加阴影；拖动至少留 40 px 在屏幕内；滚轮以光标为锚缩放 20%–400%（每格 ×1.1，接近 100% 时吸附）；双击或 Esc 关闭；右键原生菜单：复制（`Mod+C`）、保存（`Mod+S`）、恢复原始大小（`Mod+0`，缩放过才出现）、关闭；钉住不写剪切板；退出应用时全部关闭，`<数据目录>/pins/` 启动时清空。
- 性能〔建议值〕：按键到遮罩上屏 ≤ 300 ms；`XPASTE_TIMING` 开着时记 `shot 冻结 N 屏 Tms`、`shot 上屏 Tms`。
- 每个任务结束 `make check` 必须通过。

## Review Focus

1. **焦点还给原应用**：复制 / 保存 / Esc 后，用户立刻打字，字要进入截图前的前台应用；遮罩与贴图都不能激活 xPaste、不能带出面板 → Task 3 遮罩窗口与 Task 4 贴图窗口在 macOS 上都是 NonactivatingPanel，代码里不调用 `set_focus` 以外的激活；Task 8 验收行 AC-M23-09。
2. **混合 DPI 多显示器**：2x 内建屏 + 1x 外接屏（Windows 上 150% + 100%）时，窗口吸附框要贴合窗口 → Task 3 `to_local` 测试 `to_local_mixed_scale_macos_points` / `to_local_windows_physical`。
3. **截图期间再按快捷键 / 连按**：不能开第二个会话、不能重复冻结 → Task 3 `Session::try_begin` 测试 `second_begin_is_ignored_until_end`。
4. **没有屏幕录制权限（macOS）**：`CGDisplayCreateImage` 此时只返回桌面壁纸，不能把它当截图显示 → Task 3 `begin_plan(false) == BeginPlan::NeedPermission` 测试；Task 7 面板里弹权限提示。
5. **大屏内存**：两块 6K 屏一次冻结约 160 MB RGBA，会话结束（任一动作或取消）必须立即释放 → Task 3 测试 `end_drops_frames`。
