**Goal:** 补齐规格里留到 P1 的部分：视频封面与元数据、视频内联播放（AC-M08 视频部分）；复制频谱接上真实数据并在 5000 条下保持轻量（AC-M14）；“不记录这些应用”改为从已安装 / 运行中的应用里选择（M15 P1）；无障碍检查（AC-M21）；动效按 M20 表逐行对照并写进验收记录（AC-M20）；代码语言标签核对。打包、性能测量、断网验收、CI 远端属于阶段 8，不在本计划内。

**Tech Stack:** `objc2-av-foundation 0.3` + `objc2-core-media 0.3`（`AVURLAsset`、`AVAssetTrack`、`AVAssetImageGenerator`、`CMFormatDescription`）、`NSWorkspace.runningApplications`、`NSFileManager.displayNameAtPath`；`<video>` + asset 协议（CSP 已含 `media-src asset: http://asset.localhost`，不改配置）；Node 内置 `node:test`。

## Global Constraints

- `@tauri-apps/*` 只能在 `src/api/` 下 import；`src/main.ts` 之外的前端模块不碰 DOM、不碰 Tauri，并配 `*.test.ts`（`pnpm test` 自动发现，测试内 import 带 `.ts`）。
- 所有写进 `innerHTML` 的记录数据（标题、文件名、路径、编码名、应用名）经 `esc()`；`style` 里只放数字。
- 日志与事件不写剪切板内容、标题、路径：视频补全失败只记 `记录 {id} 视频元数据读取失败` / `记录 {id} 视频封面生成失败`（debug）；应用列表只记 `应用列表 {n} 项`。
- 平台层函数两端同名同签名；`cargo clippy -p xpaste-platform --all-targets --target x86_64-pc-windows-msvc -- -D warnings` 保持通过。
- 所有访问数据库、文件系统或系统接口的命令 `#[tauri::command(async)]`；锁内无 `await`、不发事件、不调 AVFoundation。
- `records.meta` 视频键（扁平，与图片 `w`/`h` 同层）：`{"duration": 83.0, "w": 1920, "h": 1080, "fps": 60.0, "codec": "H.264"}`；未知值写 0 / `""`，界面不显示。封面写 `thumbs/<id>.png`，长边 320（`THUMB_MAX`）。
- 文案与规格附录一致；新增文案（Task 8 写回附录）：`无法在预览中播放这个格式`、选择器占位 `搜索已安装或正在运行的应用，回车添加`、移除按钮名称 `移除 {名}`、封面按钮名称 `播放“{标题}”`。
- 动效值以 M20 表与原型 `:root` 曲线为准；`prefers-reduced-motion: reduce` 下全部即时；键盘触发不加动画。
- 每个任务结束 `make check` 必须通过。

## Review Focus

1. 视频源文件已移动 / 删除，或容器是 WebView 播不了的 `mkv` / `avi` / `wmv` / `flv`：预览要显示封面（有则显示）与对应提示，不能出现一个点了没反应的黑框 → Task 1 `detail_builds_video_info_from_meta_and_file`（文件不存在时 `src` 为 None）、Task 3 `canInlinePlay_only_webview_containers`，`<video>` 的 `error` 回退由交互复核验证。

3. 超过 7 天的记录、系统时间回拨导致 `copiedAt` 在未来、面板隐藏期间轨道宽度为 0：分别不画光柱 / 贴在“现在” / 不抛错 → Task 4 `xPct_maps_24h_and_earlier_zone`、`layoutBars_drops_older_than_7_days_and_survives_zero_width`。
