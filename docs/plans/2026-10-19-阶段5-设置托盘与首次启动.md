# 阶段 5：设置、托盘、首次启动 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把设置对话框（原型已带标记与样式）接到 `save_settings` 上并补齐外观、开机启动、辅助功能状态三项；托盘菜单补全暂停 / 清空 / 设置并随状态更新；单实例、快捷键注册失败通知；面板尺寸记忆与分类记忆；首次启动引导覆盖层。完成后 AC-M15、M16（03 除外）、M17、M18 可验收。

**Architecture:** 后端新增三个官方插件（single-instance、autostart、notification，全部只在 Rust 侧调用，不加前端权限），`save_settings` 在持久化后多做三件事（`set_theme`、开机启动、托盘标签），`tray.rs` 持有菜单项句柄以便改文字和图标，`panel.rs` 加尺寸记忆和“引导期间快捷键不隐藏”；新增命令 `accessibility_granted`，新增事件 `open-settings`、`confirm-clear`、`hotkey-pressed`。前端新增三个纯函数模块 `hotkey.ts`（快捷键字符串 ⇄ 标签 ⇄ 按键事件）、`settings-form.ts`（表单校验与解析）、`onboarding.ts`（引导步骤），`main.ts` 接三个 `<dialog>`：设置、确认、引导。开发构建不改系统开机启动项。

**Tech Stack:** `tauri-plugin-single-instance 2`、`tauri-plugin-autostart 2`（LaunchAgent）、`tauri-plugin-notification 2`、`WebviewWindow::set_theme`、`<dialog>` + View Transitions（无则直接切换）。

## Global Constraints

- `@tauri-apps/*` 只能在 `src/api/` 下 import；`src/main.ts` 之外的前端模块不碰 DOM、不碰 Tauri，并配 `*.test.ts`（自动发现，import 带 `.ts`）。
- 日志与事件不写剪切板内容、标题、路径；设置保存日志只写“设置已保存”及变化的字段名。
- 快捷键字符串为 Tauri 格式，修饰键顺序固定 `CommandOrControl` → `Alt` → `Shift` → 键名（大写字母、数字、`F1`–`F12`）；显示标签用原型 `hkLabel` 格式：macOS `⌘ + ⌥ + Shift + C`，Windows `Ctrl + Alt + Shift + C`（修饰键之间 ` + `）。默认 `CommandOrControl+Shift+V` → `⌘ + Shift + V` / `Ctrl + Shift + V`。
- 文案与规格说明 M15、M17、M18、附录完全一致：`设置已保存`、`至少需要包含 Mod 或 Alt`（Mod 显示为 ⌘ / Ctrl）、`该快捷键已被其他应用占用，请换一个`（`AppError::HotkeyTaken` 的 message）、`请输入 50 到 5000 之间、50 的整数倍`、`请按下组合键，至少包含一个修饰键…`、`已记录，保存后生效`、`点击输入框，然后按下新的组合键`、`将删除 N 条未置顶的记录，置顶记录会保留`、`将删除 N 条记录`、`唤起快捷键被其他应用占用，请在设置中更换`；托盘菜单：`打开 xPaste（⌘ + Shift + V）`、`暂停记录` / `继续记录`、`清空历史…`、`设置…`、`退出 xPaste`、注册失败时第一项 `更换唤起快捷键…`。新增文案（写回附录）：清空完成 `已删除 N 条记录`；无可清空记录 `没有可删除的记录`。
- 设置保存即生效（M15 规则 2）；外观在对话框内点选即预览、保存持久化、取消 / Esc / 遮罩还原为已保存值；其余项只在保存时生效。
- 任一 `<dialog>` 打开时，面板的键盘映射不响应（Esc 由对话框自己处理，关闭对话框而不隐藏面板）；面板隐藏（`panel-hidden`）时关闭所有对话框。
- 所有访问数据库或剪切板的命令 `#[tauri::command(async)]`；AppKit / 窗口调用在主线程；锁内无 `await`、不发事件。
- 平台层无新增函数；Windows 侧 `cargo clippy -p xpaste-platform --target x86_64-pc-windows-msvc` 保持通过。
- 每个任务结束 `make check` 必须通过。

## Review Focus

1. 录制只有 Shift + 字母、或只有修饰键、或功能键以外的特殊键（`Space`、`Escape`、中文输入法组合）时，不能生成非法的 Tauri 快捷键字符串 → Task 1 `hotkey.test.ts::hotkeyFromEvent_rejects_*`。
2. 保存时快捷键被占用：旧快捷键必须仍能唤起，对话框不关、错误显示在快捷键字段下、焦点回到该字段 → 后端已有恢复逻辑（`save_settings`），前端 Task 4 的错误分支；验收 AC-M15-03。
3. 对话框打开时按 Esc、Delete、Enter、`Mod + 1` 不得触发面板动作（隐藏、删除记录、复制）→ Task 4 `keymap.test.ts::dialog_open_blocks_panel_actions`。
4. 窗口隐藏期间或尺寸小于 720 × 520 时触发的 `Resized` 不得写入设置；写入值必须是逻辑像素 → Task 3 `size_to_remember_*`。
5. 忽略应用文本含中文逗号、首尾空格、重复项、空项时的解析 → Task 4 `settings-form.test.ts::parseIgnored_*`。

**Interfaces:**
- Produces（TS）：
  - `type Hotkey = { mod: boolean; alt: boolean; shift: boolean; key: string }`
  - `parseHotkey(s: string): Hotkey`（忽略大小写与空格；`CommandOrControl` / `Command` / `Control` / `Ctrl` / `Super` 都算 `mod`；未知 token 丢弃；没有键名时 `key = ''`）

  - `keyFromEvent(e: { key: string; code: string }): string | null`（`KeyA`–`KeyZ` → 字母，`Digit0`–`Digit9` → 数字，`F1`–`F12` → 原样；其余 `null`）

- Produces（Rust）：`hotkey::label(shortcut) -> String`，规则同 `hotkeyLabel`，平台用 `cfg!(target_os = "macos")`；供托盘“打开 xPaste（…）”。

```ts
test('默认快捷键的标签', () => {
  assert.equal(hotkeyLabel('CommandOrControl+Shift+V', 'macos'), '⌘ + Shift + V');
  assert.equal(hotkeyLabel('CommandOrControl+Shift+V', 'windows'), 'Ctrl + Shift + V');
  assert.equal(hotkeyLabel('CommandOrControl+Alt+C', 'macos'), '⌘ + ⌥ + C');
});
test('字符串与结构往返，修饰键顺序固定', () => {
  assert.equal(hotkeyString(parseHotkey('shift+alt+CommandOrControl+c')), 'CommandOrControl+Alt+Shift+C');
  assert.equal(hotkeyString({ mod: false, alt: true, shift: false, key: 'F2' }), 'Alt+F2');
});
test('hotkeyFromEvent_rejects_without_mod_or_alt_and_special_keys', () => {
  const ev = (o: Partial<KeyEv>): KeyEv => ({ key: '', code: '', mod: false, alt: false, shift: false, repeat: false, ...o });
  assert.equal(hotkeyFromEvent(ev({ key: 'C', code: 'KeyC', shift: true })), null);           // 只有 Shift
  assert.equal(hotkeyFromEvent(ev({ key: 'Meta', code: 'MetaLeft', mod: true })), null);      // 只有修饰键
  assert.equal(hotkeyFromEvent(ev({ key: ' ', code: 'Space', mod: true })), null);            // 特殊键
  assert.equal(hotkeyFromEvent(ev({ key: 'ç', code: 'KeyC', mod: true, alt: true })), 'CommandOrControl+Alt+C'); // 用 code 不用 key
  assert.equal(hotkeyFromEvent(ev({ key: 'F3', code: 'F3', alt: true })), 'Alt+F3');
});
```
