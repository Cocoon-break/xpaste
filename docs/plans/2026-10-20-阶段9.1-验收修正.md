> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 处理产品负责人对阶段 9 合并结果（`dev` 52631d2）手动验收时提出的 5 个问题：搜索框为空时按 Backspace 误删记录；搜索框聚焦下划线与面板顶边光谱线不贴合圆角；默认外观改为暗色；预览区头部与信息栏占高过大、信息栏换行；“常用”阈值可配置。

**Architecture:** 不加依赖、不改表结构。键位改动只在 `src/keymap.ts` 纯函数；两条光谱线改用“铺满容器 + `border-radius: inherit` + 背景图定位”的伪元素，让线随圆角裁切；默认外观只改 `Appearance` 默认值与首屏初始属性；预览区只改 CSS 与信息栏的 `title`；“常用”阈值作为 `Settings.frequent_min_uses` 进设置对话框，前端 `isFav(r, min)` 统一消费。

**Tech Stack:** Rust（tauri 2.12）、TypeScript（`node:test`）、CSS。

**Spec:** [docs/xPaste-功能规格说明.md](../xPaste-功能规格说明.md)（v0.1.10 → v0.1.11）、[docs/specs/2026-10-18-xPaste-实现设计.md](../specs/2026-10-18-xPaste-实现设计.md)（v0.11 → v0.12）。

## 自查记录

- Backspace 改为不删记录：产品负责人反馈与操作习惯冲突；保留 ⌦ 与 Mod + ⌫ 两条键盘删除路径，兼顾没有 ⌦ 键的笔记本。
- 光谱线：原型与实现都把线画在边框外侧的直线上，圆角处悬空。用铺满容器的伪元素靠 `border-radius: inherit` 裁切，不引入 `overflow: hidden`（窗口内有绝对定位的菜单与提示条）。
- 默认暗色：产品决定；只改默认值与首屏初始属性，老用户设置不动。
- 预览区：头部按钮 40 px → 32 px、信息栏两行 → 一行并给 `title`，正文内边距减小、取消 60ch 上限；列宽比例不动，避免影响列表可读性。
- 常用阈值：只在前端消费，后端只存与校验；范围 2–99（1 会让每条都成“常用”）。
