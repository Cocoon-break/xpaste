# 阶段 1：技术验证 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 ADR-001 行动项 1 的全部测量，用真实代码（不是一次性脚本）验证 Tauri 2 能否达到规格说明的唤起、监听、粘贴、浮层和资源占用要求，并把结论写回 ADR 与规格说明。

**Architecture:** 本阶段写出的 `panel.rs`、`hotkey.rs`、`clipboard.rs` 和平台层的 `watch / read_snapshot / write_text / paste / can_paste` 都是正式代码，后续阶段在其上扩展。唯一的临时物是前端的测试按钮和 `paste_text` 命令，阶段 4 用 `copy` 替换。所有测量结果以表格形式记入 ADR-001 行动项 1。

**Tech Stack:** tauri-plugin-global-shortcut 2.4、tauri-nspanel（git v2 分支，commit `18ffb9a201fbf6fedfaa382fd4b92315ea30ab1a`）、window-vibrancy 0.8、objc2 0.6 / objc2-app-kit 0.3 / objc2-foundation / objc2-core-graphics、windows 0.62。

**Spec:** [docs/specs/2026-10-18-xPaste-实现设计.md](../specs/2026-10-18-xPaste-实现设计.md)，第 3.2、6、7、8.4、8.5、10、15 节；阶段表第 1 行。前置：阶段 0 计划全部完成。

## Global Constraints

- 继承阶段 0 计划的全部约束。
- 平台相关代码只放 `crates/xpaste-platform`；`src-tauri` 只做接线（设计 3.1）。
- macOS 的 AppKit 调用在主线程执行；命令里用 `app.run_on_main_thread()` 调度（设计 3.2、8.5）。
- 日志允许写：记录 id、类型、字节数、耗时、来源应用名、是否敏感；不允许写：剪切板内容、标题、路径（设计 10）。
- 唤起目标 ≤ 100 ms（AC-M04-07），空闲 CPU < 1%，常驻内存 ≤ 150 MB（规格 5.1）。
- Windows 部分需要在 Windows 11 机器（或虚拟机）上运行；macOS 开发机只负责编译通过。CI 在两端编译。

## Review Focus

1. 面板因失焦自动隐藏后再按快捷键，`toggle` 必须按窗口真实可见状态判断，不能用自己记的布尔值，否则会出现“按一次没反应” → Task 1 Step 6 的手动用例 c。
2. 鼠标所在显示器的工作区比面板小（例如 1280 × 720 外接屏 + 960 × 640 面板加偏移）时，面板位置要钳制在工作区内，不能跑出屏幕 → Task 1 的 `place_in_work_area` 单元测试。
3. 100 ms 内连按两次快捷键，不能崩溃、不能留下半透明残影，最终状态要与按键次数一致 → Task 1 Step 6 用例 d。
4. Windows 上 `OpenClipboard` 被其他程序占用时，必须按设计 6 重试 5 次后跳过这次变化，不能 panic、不能让监听线程退出 → Task 3 Step 5 用例 c。
5. 多个 pasteboard item 中只有一个带敏感标记时，整份快照都要算敏感 → Task 3 的 `mark_sensitive` 示例程序写入两个 item，只给第二个加标记。

- [ ] **Step 1: 实现平台层**

macOS `read_snapshot`：遍历 `pasteboardItems`，任一 item 的 `types` 含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType` 或 `org.nspasteboard.AutoGeneratedType` → `sensitive = true` 且不读内容；否则读 `public.utf8-plain-text`。`watch`：线程每 300 ms 比较 `changeCount`。

Windows `watch`：线程内 `CreateWindowExW` 建 message-only 窗口（`HWND_MESSAGE` 父窗口），`AddClipboardFormatListener`，消息循环收到 `WM_CLIPBOARDUPDATE` 回调。`read_snapshot`：`OpenClipboard` 失败每 20 ms 重试，最多 5 次，仍失败返回 `Err(Clipboard)`；`EnumClipboardFormats` 枚举，`RegisterClipboardFormatW("ExcludeClipboardContentFromMonitorProcessing")` 存在，或 `CanIncludeInClipboardHistory` 值为 DWORD 0 → `sensitive`；否则读 `CF_UNICODETEXT`。`frontmost_app` 按设计 6（`GetClipboardOwner` → 前台窗口 → `QueryFullProcessImageNameW`）。
