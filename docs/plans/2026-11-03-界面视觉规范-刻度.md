# 界面视觉「刻度」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计把整个应用（面板、对话框、截图、贴图、划词卡片、录屏边框）换成「刻度」视觉，布局与交互不变。

**Architecture:** 绝大部分是 CSS：先换 `src/tokens.css` 的 token 与字体栈，再逐个样式表去掉发光、渐变、彩虹；少量 TypeScript 删掉只服务于这些效果的代码（指针光晕、频谱倒影、分类彩色带），并给 24 小时视图补每小时刻度。两个 node 测试守住 token 对比度、亮色两处同步和“发光不回来”。

**Tech Stack:** 原生 TypeScript + Vite + CSS；测试 `node --test`（`.ts` 直接跑，import 带 `.ts` 扩展名）。

**Spec:** [docs/specs/2026-11-03-界面视觉规范-刻度-设计.md](../specs/2026-11-03-界面视觉规范-刻度-设计.md)；原型 [docs/specs/2026-11-03-面板视觉原型.html](../specs/2026-11-03-面板视觉原型.html)（本地，未提交；原型里的 `new.css` 规则是面板部分的参考实现，取值以设计第 4 节为准）。

## Global Constraints

- 布局、交互、键盘、文案不改；唯一文案改动：默认视图 `#spDesc` 为“过去 24 小时”（设计 7.1）。
- M20 动效时长与缓动不变，只去掉发光成分（设计第 8 节）。
- token 取值逐字照抄设计第 4 节；不新造颜色。窗口圆角保持 14 px（设计第 6 节）。
- 界面全部系统字体：`--font-ui` / `--font-mono` 照抄设计第 5 节；数字用 `font-variant-numeric: tabular-nums`。
- 文字对比度 ≥ 4.5 : 1；非文字图标与刻线 ≥ 3 : 1。
- 代码注释、提交信息用中文；注释引用规格编号（M14、M16 等）。日志规则不涉及。
- 分支 `feat/visual-ticks`，从 `main` 拉；提交只 `git add` 改过的路径；原型 HTML 不提交。

## Review Focus

1. 系统设为亮色、应用外观“跟随系统”时走的是 `@media (prefers-color-scheme: light)` 分支，它与 `[data-theme="light"]` 必须同值 → Task 1 测试 `light_blocks_match`。
2. Windows 10 不透明材质（`data-material="opaque"`，底色 `--ink`）配色要正确 → Task 5 用模拟环境 `?os=windows` 亮暗各截一张。
3. 频谱放大后（6h / 1h / 10m）走 `winTicks` 的刻度，不能和新加的 24 小时刻度叠在一起 → Task 2 测试 `dayTicks_only_for_default_view` 由调用处保证，并在 Task 5 截一张 1h 视图。
4. 片段多选、搜索命中高亮在亮色下仍看得清（这两处保留颜色）→ Task 5 截“片段”分类多选与搜索“会议”各一张。
5. 窗口窄于 760 px 时列表与预览上下叠放，去掉分隔装饰后边界仍清楚 → Task 5 以 740 × 640 截一张。

读 `src/tokens.css` 文本，按块取 `--name: #RRGGBB` 的十六进制值（只取纯色 token；`rgb(... / a)` 跳过）。块：暗色 = 第一个 `:root {`；亮色 A = `@media (prefers-color-scheme: light)` 内的块；亮色 B = `:root[data-theme="light"] {`。

```ts
test('light_blocks_match', () => assert.deepEqual(lightA, lightB));
test('text_contrast_dark', () => {
  for (const k of ['--fg', '--muted', '--faint', '--c-text', '--c-link', '--c-code', '--c-image', '--c-video', '--c-file', '--c-fav', '--c-snip'])
    assert.ok(contrast(dark[k], '#252527') >= 4.5, k);
});
test('text_contrast_light', () => { /* 同一组 key，底色 '#F2F2F4'，>= 4.5 */ });
test('white_on_fills', () => {
  for (const b of [dark, lightB]) for (const k of ['--beam', '--danger']) assert.ok(contrast('#FFFFFF', b[k]) >= 4.5, k);
});
test('no_bundled_fonts_or_removed_tokens', () => {
  for (const s of ['@font-face', '--spectrum', '--glow-a', '--glow-b', '--sp-glow-a', '--sp-glow-b', '--sp-mirror-a', '--sp-under', '--sp-top-mix'])

});
```
