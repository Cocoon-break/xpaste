# 精简模式 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 设置里加“面板样式：完整 / 精简”；选精简后，唤起的是 400 × 520 的小面板，只有搜索栏和单行列表，空格预览，其余功能靠快捷键、右键和“更多”菜单。

**Architecture：** 后端多两个设置字段（样式、精简尺寸）和三个记录摘要字段（行数、链接地址、文件数），`panel.rs` 按样式定窗口尺寸与最小尺寸。前端同一份 `index.html`，根元素 `data-style="compact"` 时由 CSS 换布局；单行内容、分组高度、按键规则写成纯函数单测，`main.ts` 只接线。

**Tech Stack：** Rust（xpaste-core / src-tauri，Tauri 2）、原生 TypeScript + Vite、`node --test`。

**Spec：** 原型 `docs/specs/2026-11-09-精简模式-原型.html`（用户已确认，含“我替你定的几处”）；任务 1 把它写成规格说明 M27，之后的代码注释引用 M27 规则号。

## Global Constraints

- 文档、注释、日志、提交信息用中文；注释引用规格编号（“M27 规则 4”）。
- 日志里不能出现剪切板内容、标题、路径、搜索词。
- 只有 `src/api/` 调用 Tauri；改 Rust 结构同步改 `src/api/types.ts`。
- 前端测试 import 带 `.ts` 扩展名。
- 视觉照「刻度」token（`src/tokens.css`），不新增颜色；尺寸取原型里的值：行高 36、缩略图 20、搜索框高 36、窗口 400 × 520、最小 360 × 400。
- 运行应用只用 `make dev-isolated`。`git add` 按路径。提交前 `make check`。
- 分支 `feat/compact-mode`（已建），合并走 PR。

## Review Focus

1. **完整 ↔ 精简来回切换时窗口尺寸**：两种尺寸各记各的；拖小了精简面板再切回完整，完整面板仍是原来的大小；最小尺寸跟着样式变（完整 720 × 520，精简 360 × 400）。测试放任务 3（`remember_size_picks_field_by_style`）。
2. **旧设置文件没有新字段**：升级后读出默认值（完整、400 × 520），不报错不丢其他设置。测试放任务 2。
3. **搜索框里输入空格**：有搜索词时空格是字符（“周四 会议”），不打开预览；输入法组字中不响应。测试放任务 4（keymap）。
4. **多行文本只有空行或末尾换行**：“a\n\n” 算 1 行，不显示“2 行”。测试放任务 2（store）。
5. **精简样式下列表虚拟滚动与删除补位**：行高 36 而不是 56，删除补位、滚动到选中行都按当前行高算。测试放任务 4（`layout` 带行高）。
