# 阶段 15.1 划词翻译与语言包下载 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在阶段 15 翻译的基础上做三件事：
1. 每段译文都标出翻译方式，并能单次换用另一种；
2. 在 xPaste 里一键下载系统翻译语言包；
3. 全局划词翻译快捷键，译文卡片弹在鼠标旁。

**架构：**
- **翻译方式：** 记在译文上，存库为 `translation_engine`；增量、命令返回值都带上它，前端用纯函数把它变成“系统翻译” / “AI（模型 ID）”。
- **语言包下载：** 用 Swift 桥接新增的 `xp_tr_prepare`，把一个 1×1 SwiftUI 视图临时塞进当前显示的 xPaste 窗口，调起系统确认。
- **划词翻译：** 新的全局快捷键角色 `translate`。平台层模拟复制（macOS `⌘C`，Windows `Ctrl+Insert`），再在预建的、不激活应用的 `tr-card` 窗口里显示译文，翻译复用 `translate::exec`。

**技术栈：** Rust（Tauri 2、rusqlite、reqwest）、Swift（Translation、SwiftUI、AppKit）、原生 TypeScript（Node 原生测试）。

**规格：** `docs/specs/2026-10-30-划词翻译与语言包下载-设计.md`（下文称“设计”）。阶段 15 的设计 `docs/specs/2026-10-29-翻译-设计.md` 与规格说明 M26（v0.1.26）是现状。

    - 复制：`已复制译文`；按钮 `复制译文 ↵`、`关闭 Esc`。

  - 模拟复制前等修饰键松开，最多 500 ms；复制后最多等 400 ms 看剪切板有没有变。

## 重点检查（没有现成测试覆盖、最可能出问题的地方）

1. 按快捷键时 `⌥⇧` 还没松开就发了复制，变成 `⌥⇧⌘C`，Windows 上是 `Ctrl+Alt+Shift+Insert` → Task 5 的 `wait_modifiers_released` 纯逻辑测试，加真机验收 AC-M26-26。
2. Windows 终端里没有选区时被中断：必须用 `Ctrl+Insert`，代码里不能出现模拟 `Ctrl+C` → Task 5 第 3 步的 grep 检查。
3. 卡片抢走前台，关掉后字打不回原应用 → Task 6 沿用截图遮罩的 NSPanel 写法；真机验收 AC-M26-20。
4. 换用翻译方式后，面板里存的译文、标注、“重新翻译”的方式三者不一致 → Task 1 的 `engine_follows_stored_translation`，Task 2 的 `trBlockHTML` 标注测试。
5. 语言包下载期间面板或卡片被关掉，回调落在已经隐藏的窗口上 → Task 3 规定视图在回调里移除，回调只经 channel 交回；`translate_prepare` 不设超时，但命令要能被前端忽略（前端按序号丢掉迟到结果）。

### Task 1：翻译方式存库、标注与单次指定

**文件：**

- `src/api/commands.ts`、`src/api/types.ts`

**接口：**
- 翻译方式标签（engine tag）是一个字符串：`"system"` 或 `"openai:{模型 ID}"`。
- `xpaste_core::translate::engine_label(tag: &str) -> String`：`"system"` → `系统翻译`；`"openai:gpt-4o-mini"` → `AI（gpt-4o-mini）`；无法识别的 → 空串。前端另写一份同规则的 TS 函数（Task 2）。
- 迁移第 9 项：`ALTER TABLE records ADD COLUMN translation_engine TEXT;`。`set_ocr` 写新文字、`update_snippet` 改内容时，与另外两列一起置 NULL。
- `Store::set_translation(&self, id: i64, text: &str, lang: &str, engine: &str) -> Result<bool, CoreError>`
- `RecordDetail.translation_engine: Option<String>`
- `translate::Cfg::tag(&self) -> String`：System → `"system"`，OpenAi → `format!("openai:{}", self.model.trim())`。
- `translate::cfg_for(s: &Settings, engine: Option<Engine>) -> Cfg`：`None` 同 `cfg(s)`；`Some(e)` 时强制用 `e`，其余字段照设置。
- `Delta { id, lang, engine: String, text }`（`engine` 为 tag）。
- `translate_record(app, id: i64, again: bool, engine: Option<String>) -> Result<Translated, AppError>`。`Translated { text, lang, engine }`。选哪种方式：
  - `engine` 给了（`"system"` / `"openai"`）：用它（“换用”按钮）。
  - 没给、`again` 为真、库里有译文：用库里译文的方式（“重新翻译”沿用，设计 §3.4）。
  - 其余情况用设置。
  - 指定的方式用不了（系统翻译在 macOS 26 以下；AI 未配置）：报对应错误（`TranslateOs` / `TranslateConfig`），不改用另一种。
- `translate_engines() -> Engines { system: bool, openai: bool, model: String }`，async 命令：
  - `system` = `translate_supported()`；
  - `openai` = 接口地址、模型 ID 都不为空；
  - `model` = 去掉首尾空白的模型 ID。
- TS：`translateRecord(id, again, engine?: 'system' | 'openai')`、`translateEngines()`；类型 `Translated.engine`、`TranslateDelta.engine`、`RecordDetail.translationEngine`、`Engines`。

### Task 2：面板与设置里的标注、换用按钮

**文件：** `src/translate.ts`、`src/translate.test.ts`、`src/main.ts`、`index.html`、`src/styles.css`

**接口（`src/translate.ts`）：**
- `export function engineLabel(tag: string): string`：规则同 Rust 的 `engine_label`。
- `Tr` 加 `engine: string`（tag）。`trAfterDelta(prev, lang, engine, piece)` 和 `trAfterEnd(prev, res)` 都带上 engine；`res` 成功时含 `engine`，失败时 `engine` 取请求时的方式。
- `export function otherEngine(tag: string, avail: { system: boolean; openai: boolean; model: string }): 'system' | 'openai' | null`：当前是 system 且 `avail.openai` → `'openai'`；当前是 openai 且 `avail.system` → `'system'`；其余 → `null`。
- `trBlockHTML(tr: Tr, mono: boolean, other: 'system' | 'openai' | null): string`：
  - 标题行按全局约束的面板格式加上 `· {engineLabel}`；模型 ID 超过 24 个字截断，完整值放 `title`。
  - `other` 不为 null 且状态不是 busy 时，多一个按钮 `[data-tr="switch"][data-engine=…]`，文字为 `换用 AI 翻译` / `换用系统翻译`。
  - 失败、中断时也带这个按钮。

### Task 3：一键下载语言包

**文件：**
- `crates/xpaste-platform/swift/translate.swift`、`crates/xpaste-platform/src/{lib.rs,macos.rs,windows.rs}`
- `src-tauri/src/commands/translate.rs`、`src-tauri/src/translate.rs`（缺语言包报错文案）
- `src/main.ts`、`index.html`、`src/api/{commands.ts,types.ts}`

**接口：**
- Swift：`xp_tr_prepare(source: *const c_char, target: *const c_char, window: *mut c_void /* NSWindow */, ctx, cb(ctx, code: i32))`。
  - 在主线程把一个 1×1 透明的 `NSHostingView`（`.translationTask(Configuration(source:target:))`，任务里调 `prepareTranslation()`）加进 `window.contentView` 作为子视图。
  - 回调码：0 已下载 / 1 用户取消 / 2 失败；回调前把视图移除。
  - `source` 为空串时用 `en`。
- `xpaste_platform::translate_prepare(source: &str, target: &str, window: *mut c_void) -> Result<PackStatus, SysTranslateError>`：
  - 必须在**非主线程**调用；函数内部用 `dispatch` 到主队列挂视图，然后阻塞等回调，不设超时。
  - Windows 返回 `Err(Unsupported)`。
  - 完成后再查一次 `translate_pack` 作为返回值，取消时返回 `Download`。
- 命令 `translate_download(app, window_label: String, source: String, target: String) -> Result<String /* "installed" | "download" */, AppError>`，async：
  - 主线程上取窗口的 `ns_window()` 指针，然后 `spawn_blocking(translate_prepare)`。
  - 立即失败（code 2）时：按 `open_translation_settings` 的方式打开“语言与地区”页，返回 `AppError::Translate("在这一页最下方点“翻译语言…”，下载{源}和{目标}")`。
- `Fail::Pack` 的文案改为 `系统翻译还没有{源语言}和{目标语言}的语言包`。源语言名用 `Lang::from_code(source).map(label)`，认不出时用系统的本地化名或原代码。
- 前端：
  - 设置“语言包”一行：按钮文字 `下载语言包`；点后状态为 `下载中…`，结果回来重查。
  - 面板缺语言包的提示条：按钮 `下载语言包`（`window_label` 为面板窗口），下载完成后自动 `doTranslate` 重试。
  - 删掉原来“打开系统设置”的按钮路径；`open_translation_settings` 只用作兜底。
- TS：`translateDownload(windowLabel, source, target)`。缺语言包错误要带回源语言代码：`AppError` 的 `translatePack` 新增可选字段 `source`，Rust 侧序列化时附上。

### Task 5：平台层模拟复制

**文件：**
- `crates/xpaste-platform/src/{lib.rs,macos.rs,windows.rs}`
- 平台无关的纯逻辑放 `lib.rs`，带测试

**接口：**
- `pub fn copy_selection() -> Result<bool, PlatformError>`：
  1. 等修饰键松开，最多 500 ms，每 10 ms 查一次。
  2. 记下剪切板序号（`change_count()`），发送复制按键：
     - macOS：`CGEvent` 键码 8（C），flags 只带 `MaskCommand`；
     - Windows：`SendInput` 发 `VK_CONTROL` 按下、`VK_INSERT` 按下/松开、`VK_CONTROL` 松开。
  3. 每 20 ms 查一次序号，最多 400 ms。变了返回 `Ok(true)`，否则 `Ok(false)`。
  - macOS 没有辅助功能权限时返回 `Err(PlatformError::…)`（沿用 `paste` 的权限判断），调用方据此走“翻译剪切板”。
- `pub(crate) fn wait_until(mut done: impl FnMut() -> bool, step_ms: u64, max_ms: u64) -> bool`：纯轮询助手，测试用假时钟或短时长跑。
- `modifiers_down() -> bool`：
  - macOS 用 `CGEventSourceFlagsState(kCGEventSourceStateCombinedSessionState)`，查 Command、Option、Shift、Control 中任一位；
  - Windows 用 `GetAsyncKeyState`，查 `VK_MENU`、`VK_SHIFT`、`VK_CONTROL`、`VK_LWIN`、`VK_RWIN` 的最高位。

### Task 6：划词卡片的后端流程与窗口

**文件：**
- `src-tauri/src/trcard.rs`（替换 Task 4 的占位实现）、`src-tauri/src/lib.rs`
- `src-tauri/src/events.rs`、`src-tauri/capabilities/*`（新窗口的权限）、`src-tauri/tauri.conf.json`（如需）
- `card.html`、`vite.config.ts`（加 `card` 入口）

**接口：**
- 窗口 `tr-card`：启动时预建、隐藏，透明、无边框、不在任务栏、加载 `card.html`。
  - macOS：照 `shot.rs` 的贴图窗口（`NS_FLOATING_WINDOW_LEVEL`、不激活应用的 NSPanel），但要能成为 key window，以便接收回车和 Esc。照遮罩的写法。
  - Windows：照遮罩“不抢前台”的写法。
- `trcard::pressed(app)`：后台线程上执行以下步骤。
  1. 前台应用在“不记录这些应用”里（`capture::is_ignored_app`），或 `skip_sensitive` 开着且前台是密码管理器：发 `trcard-show { kind: "blocked" }`，不复制。
  2. 调 `copy_selection()`：
     - `Ok(true)`：用 `read_snapshot(skip_sensitive)` 读剪切板，`sensitive` 时按 blocked 处理；取文字。
     - `Ok(false)`：直接读剪切板里的文字。
     - `Err`（无权限）：读剪切板文字，并带 `noAccess: true`。
  3. 没有文字：发 `trcard-show { kind: "empty", hotkey: <显示格式> }`。
  4. 有文字：在会话里留住原文，算出卡片位置，发 `trcard-show { kind: "text", source: <原文前 40 字>, engine: <tag>, noAccess }`，然后显示窗口、交给键盘，开始翻译。
     - 用 `translate::exec(cfg_for(settings, engine), text, …)`；
     - 增量 `emit_to("tr-card", TRANSLATE_DELTA, Delta { id: None, … })`；
     - 结束时发 `trcard-done { ok, text?, error?, errorKind?, source? /* 缺语言包时的源语言 */ }`。
- 会话：`Mutex<Option<CardSession { seq: u64, text: String }>>` 放进 `AppState`。
  - 再按一次快捷键，`seq + 1`。旧请求的 `on_delta` 检查到 `seq` 变了就返回 false，中止，并且不再发事件。
- 命令：
  - `trcard_again(seq: u64, engine: Option<String>)`：用会话原文重翻（换用 / 重新翻译），async。
  - `trcard_copy(text: String)`：普通写入剪切板，进历史。
  - `trcard_close()`：`orderOut`，交还键盘，`seq + 1` 中止进行中的请求。
  - `trcard_blur()`：窗口失去键盘时由前端调用，等同 close。
- 卡片位置：`pub fn place_card(cursor: (f64, f64), card: (f64, f64), work: Rect) -> (f64, f64)`。
  - 放在指针右下方 12 px；放不下就向左 / 向上翻转，并夹在工作区内。
  - 卡片的初始尺寸按 360 × 160 估算，前端渲染后调 `trcard_resize(h)` 只改高度。高度变化时保持“向上翻转”的那条边不动（`trcard_resize` 里处理）。
  - 指针位置与所在屏的工作区：macOS 用 `NSEvent::mouseLocation` 和 `NSScreen::visibleFrame`，Windows 用 `GetCursorPos` 和 `MonitorFromPoint` / `GetMonitorInfo` 的 `rcWork`，照现有平台层风格新增 `cursor_and_work_area()`。
- 日志：`trcard copied=<bool> chars=N`、`trcard 无文字`、`trcard 排除应用`。
