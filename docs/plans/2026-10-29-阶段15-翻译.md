# 阶段 15 翻译 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 面板里对选中记录按 `Mod + T` 翻译，截图框选后按 `T` 翻译；翻译方式可选 macOS 系统翻译（本机）或 OpenAI 兼容接口（流式）。

**架构：**
- 纯逻辑放在 `xpaste-core/src/translate.rs`：语言、方向判断、请求体、SSE 解析、错误文案。
- macOS 系统翻译放在 `xpaste-platform`：一个 Swift 文件导出 C 函数，由 `build.rs` 编成静态库。
- `src-tauri/src/translate.rs` 负责按设置分发到两种方式：OpenAI 走 `reqwest` 异步流式，系统翻译走阻塞调用。
- 面板通过 `translate_record` 命令翻译，增量走 `translate-delta` 事件，最终结果在命令返回值里。
- 截图在 `shot_finish` 里新增 `translate` 动作，译文增量只发给发起的遮罩窗口。

**技术栈：** Rust（rusqlite、reqwest 0.13）、Swift（Translation、NaturalLanguage 框架）、Tauri 2、原生 TypeScript（Node 原生测试）。

**规格：** `docs/specs/2026-10-29-翻译-设计.md`（下文称“设计”）。

**与设计的一处偏差（不改变行为）：** 设计 §4.5 写的是结束时发 `translate-done` 事件。这里改成 `translate_record` 命令的返回值（成功为译文，失败为错误），面板的 Promise 不管当前选中哪条都会收到结果，所以不需要这个事件。

- 日志里不能出现原文、译文、API Key、Base URL；只记 id、字数、耗时、HTTP 状态码、错误类别（CLAUDE.md 横切约束，设计 §4.1）。
- 代码注释先引用“设计 §x.y”，到 Task 8 写进规格说明后统一改成 “M26 规则 n”。
- 迁移只往 `MIGRATIONS` 末尾追加（当前 7 项，这次是第 8 项：v7 → v8），并补一个从 v7 升级的测试。

- 原文上限 `10000` 个字符；OpenAI 连接超时 10 秒，读空闲超时 30 秒（`read_timeout`），没有总时长上限；系统翻译 30 秒超时；都不重试。
- 增量合并：后端每 ≥ 50 ms 发一次 `translate-delta`，结束时把剩下的发完。
- 目标语言代码与显示名：`zh-Hans` 简体中文、`zh-Hant` 繁體中文、`en` English、`ja` 日本語、`ko` 한국어。
- 文案（照抄）：
  - 未配置：`请先在设置的“翻译”里配置接口`（按钮 `去设置`）
  - 401/403：`API Key 无效或没有权限`
  - 404：`接口地址或模型 ID 不对`
  - 429：`请求太频繁或额度不足，稍后再试`
  - 其他非 2xx：`翻译服务出错（HTTP {状态码}）`
  - 连不上：`连不上翻译接口，请检查网络或接口地址`
  - 超时：`翻译超时`
  - 格式不对或为空：`翻译服务返回的内容无法识别`
  - 超长：`内容太长，最多翻译 10000 字`
  - 缺语言包：`需要先下载{源语言}→{目标语言}的翻译语言包`（按钮 `打开系统设置`）
  - 语言不支持：`系统翻译不支持这种语言`
  - 系统太旧：`系统翻译需要 macOS 26，请在设置里改用 OpenAI 兼容接口`（按钮 `去设置`）
  - 系统翻译其他错误：`系统翻译失败`
  - 复制：面板 `已复制译文`；截图 `已复制译文 · {N} 字，已加入历史`
  - 区块标题：`翻译中…`、`译文 · {语言名}`、`翻译中断`、`翻译失败`
  - 截图忙碌：`正在翻译…`；工具栏提示 `识别文字并翻译  T`
  - 设置 Base URL 校验：`请输入 http:// 或 https:// 开头的地址`
- 每个任务提交前跑 `make check`，按路径 `git add`。分支为 `feat/translate`（已建，设计文档已提交）。

## 重点检查（没有现成测试覆盖、最可能出问题的地方）

1. 用户把 Base URL 填成完整地址 `…/v1/chat/completions` 或带了末尾 `/`：仍然请求到 `…/v1/chat/completions`，不会拼成两遍 → Task 1 的 `endpoint_normalizes_base_url`。
2. SSE 的一行被拆在两次网络读取里，甚至拆在一个汉字的 UTF-8 字节中间：译文不能乱码、不能丢字 → Task 4 的 `stream_survives_split_lines`。
3. 兼容服务的第一段只有 `role`、没有 `content`，或者推理模型先发 `reasoning_content`：这些段跳过，不报错 → Task 1 的 `sse_skips_role_and_reasoning_chunks`。
4. 服务返回 200，但 SSE 里是 `data: {"error":…}`：要报「翻译服务返回的内容无法识别」，不能把空译文存进数据库 → Task 1 的 `sse_error_object_is_bad`，以及 Task 4 的 `empty_result_is_error`。
5. 用户粘贴 API Key 或模型 ID 时带了首尾空格或换行：保存时去掉 → Task 2 的 `translate_settings_are_trimmed_and_validated`。

**接口（在 `lib.rs` 里定义，两端导出同名函数）：**
- `pub enum PackStatus { Installed, Download, Unsupported }`
- `pub enum SysTranslateError { OsTooOld, NotInstalled { source: String }, Unsupported, Timeout, Failed }`
  - `source` 是源语言代码，用来拼文案。
  - `Failed` 不带消息，日志另记错误码。
- `pub fn translate_supported() -> bool`：macOS 26 及以上返回 true；Windows 恒为 false。
- `pub fn translate_pack(target: &str) -> PackStatus`：查英语 ↔ 目标语言的语言包状态；目标是 `en` 时查简体中文 ↔ 英语。
- `pub fn translate_text(text: &str, target: &str) -> Result<String, SysTranslateError>`：阻塞调用，30 秒超时。

**Swift 侧导出的 C 函数**（名字固定，Rust 侧按这些名字声明 `extern "C"`）：
- `xp_tr_pack(target: *const c_char) -> i32`：返回 0 已下载，1 需要下载，2 不支持。
- `xp_tr_translate(text: *const c_char, target: *const c_char, ctx: *mut c_void, cb: extern "C" fn(ctx, code: i32, out: *const c_char))`
  - `code` 的含义：0 成功（`out` 为译文），1 缺语言包（`out` 为源语言代码），2 不支持，3 其他失败。

**接口：**
- `shot::ocr_text(png: &[u8]) -> Result<Option<String>, AppError>`：从现有 `ocr()` 拆出来，`ocr()` 改为调用它，行为不变。
- `ShotOutcome` 新增 `text: Option<String>`，只有翻译动作有值，前端类型同步。
- `Action::Translate` 在 `run_action` 里的流程：
  1. 调 `ocr_text`，没有文字时返回 `Err(Invalid("选区里没有识别到文字"))`，走现有的失败回选区路径；
  2. 用 `tauri::async_runtime::block_on(translate::run(...))` 翻译；
  3. `on_delta` 里先检查 `session(app).is_current(generation)`，截图已结束就返回 false 中止；否则经合并器 `emit_to(label, TRANSLATE_DELTA, { id: null, lang, text })`。
  4. 成功返回 `ShotOutcome { action: "translate", chars, text: Some(译文), copied: false, file: None }`。
- `finish()` 对 `Action::Translate` **不调用** `enter_toast`。`finishing` 保持认领，所以卡片显示期间不能再做第二个动作。
- `shot_copy_text(app, generation: u64, text: String) -> Result<(), AppError>`：
  - 不是当前这一次截图时报 `Invalid("截图已结束")`；
  - 否则用 `xpaste_platform::write(&[text_flavor(&text)])` 写剪切板，这样会进历史，同识别文字；
  - 然后 `enter_toast(app, generation)`。
- `export function placeCard(sel: Rect, card: { w: number; h: number }, W: number, H: number): { x: number; y: number }`（`geom.ts`）：
  - 位置依次试右侧、左侧、下方、上方，间距 8，离屏幕边至少 8；都放不下时，放在选区内右上角，离边 8。
  - 卡片在第一段到达时定位一次，之后不再挪动。
