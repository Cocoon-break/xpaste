# 阶段 3：面板界面 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `docs/xpaste-prototype.html` 迁移成正式面板界面，接到阶段 2 的数据与事件上：虚拟列表、搜索、分类、预览（视频元数据除外）、右键菜单、删除撤销、置顶、提示条、键盘操作；替换阶段 1/2 的临时界面和临时命令。

**Architecture:** 前端仍是单页 vanilla TS：原型的 `<style>` 整体进 `src/styles.css`，面板 `<body>` 进 `index.html`，脚本进 `src/main.ts`（DOM 与编排）；与 DOM 无关的纯逻辑拆成 `src/format.ts`、`src/color.ts`、`src/view.ts`、`src/virtual-list.ts`、`src/keymap.ts`，各配 `*.test.ts`。数据源从原型的 `S.items` 换成 `bootstrap()` 返回的摘要 + `record-*` 事件增量更新；详情按需 `get_record`。后端只做小补充：`copy(id, paste)` 取代临时的 `paste_text`，新增 `copy_text`、`open_url`、`reveal_file`、`panel-hidden` 事件、`bootstrap.paused`，删除 `clipboard-changed`。

**Tech Stack:** Vite 8 + TypeScript 6（无框架）、Web Animations API、`<dialog>`、CSS `@starting-style`；Rust 端 `tauri-plugin-opener 2`；字体 Geist / Unbounded / JetBrains Mono woff2 本地打包。

**Spec:** [docs/specs/2026-10-18-xPaste-实现设计.md](../specs/2026-10-18-xPaste-实现设计.md) §2（Q5、回写项 2、5）、§8.2–8.5、§9 全部、§13（前端纯函数行）；阶段表第 3 行。规格说明 M04（布局、标题栏）、M05、M06、M07、M08（视频除外）、M09（前端触发与提示）、M10、M12、M13、M16（字体、类型色）、M19、M20（降级为 P0 的部分）、M21、附录文案。原型 [docs/xpaste-prototype.html](../xpaste-prototype.html) 是界面的实现依据，迁移时少改不重写。

## Global Constraints

- `@tauri-apps/*` 只能在 `src/api/` 下 import；`src/main.ts` 之外的前端模块不碰 DOM、不碰 Tauri，并配 `*.test.ts`（`pnpm test` = `node --test 'src/**/*.test.ts'` 自动发现，测试内 import 带 `.ts` 后缀）。
- 所有写进 `innerHTML` 的记录数据（标题、文本、路径、URL、应用名、语言）必须经 `esc()`；颜色值注入 `style` 前必须再过 `isHex()`；`<a href>` 只接受 `^https?://`，点击一律 `preventDefault()` 后调 `openUrl`。
- 日志与事件不写内容、标题、路径；前端 `info()` 日志同样只写 id、数量、耗时。
- 类型颜色、中性色、三条曲线（enter `cubic-bezier(.22,1,.36,1)`、move `cubic-bezier(.25,1,.5,1)`、spring `cubic-bezier(.34,1.56,.64,1)`）以原型 `:root` 为准，原样迁移；`prefers-reduced-motion: reduce` 下全部动效即时切换（原型末尾的全局规则保留）。
- 键盘触发的操作不加动画：`e.detail === 0` 或 `e.repeat` 时走 `instant` 路径（原型 `instantly()` 与 `select(..., { instant })` 的写法）。
- 行高固定 56 px（`.row-in`），分组标题固定 34 px（给 `.ghead` 加 `height: 34px; box-sizing: border-box`）；虚拟列表预渲染上下各 8 行。
- 文案与规格说明附录完全一致：删除提示 `已删除“标题前 14 字…”`、置顶 `已置顶，会一直显示在列表最上方`、取消 `已取消置顶`、恢复 `已恢复`、颜色格式 `已复制 rgb(111, 139, 255)`、无法粘贴 `已复制，在目标应用中按 Mod + V 粘贴`、常用 `这条已经用了 3 次，已加入“常用”`；`AppError.message` 直接用作提示条文案。
- 事件名 kebab-case，Rust `events.rs` 与 `src/api/events.ts` 各一份常量；类型字段 camelCase，`src/api/types.ts` 与 Rust 一一对应。
- 所有访问数据库或剪切板的命令 `#[tauri::command(async)]`，锁内无 `await`，持锁期间不发事件。
- 字体文件本地打包（`src/fonts/*.woff2` + `@font-face`），`index.html` 不得有任何外链；CSP 不改（字体走 `default-src 'self'`）。
- 每个任务结束 `make check` 必须通过。

**Files:**

**Interfaces:**
- Consumes：`Store::flavors(id)`, `Store::detail(id)`（`files[].exists`）, `Store::bump_use(id, move_to_top, now)`, `xpaste_platform::write(&[Flavor]) -> Result<u64>`, `write_text`, 现有 `plan_paste` / `paste_on_main` / `panel::hide` / `panel::reshow`。
- Produces：
  - `#[tauri::command(async)] pub async fn copy(app: AppHandle, state: State<'_, AppState>, id: i64, paste: bool) -> Result<CopyResult, AppError>`，顺序严格按设计 8.5：
    1. `detail(id)` 为 `None` → `AppError::Invalid("记录不存在".into())`；`files` 任一 `!exists` → `Err(FileMissing)`，不写剪切板。
    2. `flavors(id)` 为空 → `Err(ClipboardWrite)`。
    3. `writing=true` → `platform::write(&flavors)` → 记 `last_write_seq` → `writing=false`；失败 `Err(ClipboardWrite)`。
    4. `bump_use(id, settings.move_to_top, now_ms())`（锁外发）`emit_summary(RECORD_UPDATED, id)`。
    5. `!paste` → `Ok(Copied)`；否则沿用 `paste_text` 的 `plan_paste` → `CopiedOnly { reason }` / 隐藏面板 → `paste_on_main` → `Pasted`，失败 `reshow` + `CopiedOnly { reason: "pasteFailed" }`。
  - `#[tauri::command(async)] pub fn copy_text(state: State<'_, AppState>, text: String) -> Result<(), AppError>`：`writing` / `last_write_seq` 同上包住 `write_text`；不隐藏面板、不改记录。监听线程因 `is_self_write` 跳过，所以不产生新记录（AC-M08-02）。
  - 把写剪切板的三步抽成 `fn write_marked(state: &AppState, f: impl FnOnce() -> Result<u64, PlatformError>) -> Result<(), AppError>` 供两者共用。
  - TS：`copy(id: number, paste: boolean): Promise<CopyResult>`、`copyText(text: string): Promise<void>`。
