# 阶段 11：复制频谱时间缩放与霓光镜面 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 复制频谱可以围绕指针放大到 5 分钟、平移、一键复位，并换成原型方案 B 的霓光镜面视觉（白顶光柱、22 px 倒影、选中光束、放大态概览条）。

**Architecture:** 时间窗 `Win | null` 是频谱的唯一新状态，纯计算（夹紧、缩放、平移、坐标、刻度、概览条）全部进 `src/spectrum.ts` 并有测试；`main.ts` 只加手势监听、按帧合并的重绘与几处选中联动；视觉全在 `styles.css` 与 `index.html` 的频谱块。不碰 Rust、不碰设置与持久化。

**Tech Stack:** TypeScript（纯模块 + DOM）、CSS、`node --test`、无头 Chrome 截图复核。

**Spec:** [docs/specs/2026-10-20-复制频谱缩放与霓光镜面-设计.md](../specs/2026-10-20-复制频谱缩放与霓光镜面-设计.md)（含原型 [2026-10-20-复制频谱缩放与视觉原型.html](../specs/2026-10-20-复制频谱缩放与视觉原型.html) 方案 B，`#1h` 看放大态）。执行者读设计稿的 §4 全部小节。

## Global Constraints

- 列表不受缩放影响：不改 `visible()`、计数、搜索、分类（设计 §2 非目标）。
- 时间窗只在内存：面板隐藏（`hidden()`）与收起频谱时置回 `null`；不写设置。
- 窗口长度 5 min ≤ 长度 ≤ 24 h；范围不超出 `[now − 24 h, now]`，碰边整体贴边；长度达 24 h 即 `null`（默认视图）。
- 贴着 now 的窗口 `pinned = true`，每次重绘 `end = now`；离开 now 即 `pinned = false`。
- 手势期间（滚轮、捏合、拖动）不加缓动；预设 / 双击 / 概览条 / 鼠标选中出窗平移只让光束与概览条窗框过渡 360 ms（`--ease-move`），光柱与刻度直接重画；键盘触发即时；`prefers-reduced-motion` 下只保留不透明度过渡。
- 只有用户直接的选中（方向键、数字键、列表行点击 / 右键、光柱点击、撤销恢复）才平移窗口；搜索自动选中、新记录、删除顺延不平移。
- 频谱与倒影、概览条、预设对读屏 `aria-hidden`；预设按钮 `tabindex="-1"`。
- 日志里不出现记录内容（既有约束，本阶段不新增日志）。
- 不运行开发版除非满足按键门槛（面板可见且用户空闲 ≥ 20 s，每段按键前检查）；只用 `make dev-isolated`，按进程组杀；不满足就把实机验证列为待用户。
- 提交只按路径 `git add`；提交信息末尾 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`。
- `make check` 必须通过（`cargo fmt --check`、clippy、Rust 测试、`pnpm test`、`pnpm build`）。

## Review Focus

1. 面板打开着复制新内容，而频谱已放大到固定窗口（未贴 now）：窗口必须不动、光柱不长、概览条多一个点；贴 now 的窗口里新光柱在右端升起并脉冲（Task 3 的 `record-added` 路径与 Task 1 `followNow` 测试）。
2. 每分钟定时重绘（`setInterval` 60 s）与 `pinned` 窗口：`end` 随 `spNow` 走，刻度不漂（Task 1 `ticks` 整分钟对齐测试；Task 3 在 `renderSpectrum` 开头调用 `followNow`）。
3. 搜索框连续输入时每次结果自动选中第一条：窗口不能跳（Task 3 只在带 `pan` 的 `select` 调用里平移；Task 1 无需测试）。
4. 拖动平移后松手：不能触发光柱点击选中；拖动阈值 2 px（Task 3 `spDragged` 标志）。
5. 亮色主题下白顶光柱与倒影：顶端用 `color-mix(in srgb, var(--tc) 40%, #fff)`，光晕减半（Task 2 截图复核亮色）。

```ts
export const MIN_SPAN = 5 * 60e3;
export const HOUR = 36e5;
/** 放大后的时间窗；pinned：右端贴着 now，随时间滑动 */
export interface Win { start: number; end: number; pinned: boolean }
export const spanOf = (w: Win) => w.end - w.start;
/** 夹紧：长度夹到 [MIN_SPAN, DAY]，范围夹到 [now − DAY, now]（保长度整体贴边）；长度达 DAY 返回 null。pinned = end ≥ now − 1000 */
export function clampWin(start: number, end: number, now: number): Win | null;
/** pinned 窗口随时间走：end = now，start = now − 长度；非 pinned 原样返回 */
export function followNow(w: Win, now: number): Win;
/** 轨道横向比例（0–1）对应的时间：默认视图只在 24 h 区内有意义，比例 < 0.06 按 now − DAY */
export function timeAt(w: Win | null, fracX: number, now: number): number;
/** 围绕 fracX 处的时间缩放：新长度 = 当前长度 × factor（默认视图当前长度为 DAY），指针下的时间保持在指针下 */
export function zoomWin(w: Win | null, fracX: number, factor: number, now: number): Win | null;
/** 平移 dt 毫秒（正值向“现在”），经 clampWin */
export function panWin(w: Win, dt: number, now: number): Win | null;
/** 以 center 为中心、长度 span 的窗口，经 clampWin；center 在 now − DAY 之前时按 now − DAY 对待 */
export function centerWin(center: number, span: number, now: number): Win | null;
/** 记录时间 → 轨道百分比：w 为 null 用 xPct(now − t)；否则线性映射，落在 [−1, 101] 之外返回 null */
export function xOf(w: Win | null, copiedAt: number, now: number): number | null;
/** 主 / 次刻度步长（ms），主刻度数 ≤ 8：见设计 §4.5 的表 */
export function tickStep(span: number): [number, number];
/** 放大态刻度：t 对齐到步长整数倍，x 为百分比；major 为主刻度。贴 now（end ≥ now − 1000）时末尾追加 { x: 100, t: now, major: true, now: true } */
export function ticks(w: Win, now: number): { x: number; t: number; major: boolean; now?: boolean }[];
/** 概览条窗框：相对 24 h 的 left / width 百分比，width 最小 0.6 */
export function miniWin(w: Win, now: number): { left: number; width: number };
/** 放大态标题行文字：`HH:mm – HH:mm（N 小时 | N 分钟）`，整小时不带小数，非整小时一位小数 */
export function winLabel(w: Win, fmt: (t: number) => string): string;
// layoutBars 增加可选参数 win，位置改用 xOf(win, r.copiedAt, now)，其余不变
export function layoutBars(recs, now, widthPx, isMatch, freshId?, win?: Win | null): Layout;
```

- [ ] **Step 3: 实现上述签名**
