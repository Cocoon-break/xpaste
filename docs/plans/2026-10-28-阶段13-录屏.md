# 阶段 13：录屏（macOS）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 macOS 上按录屏快捷键，复用截图遮罩选区域（窗口、框选或全屏），倒计时 3 秒后用 ScreenCaptureKit 录成 H.264 MP4（可带系统声音和麦克风）。录制中选区外有一圈边框、菜单栏显示计时；再按快捷键或点菜单“停止录制”结束。视频存进录屏文件夹，并作为视频记录进入历史。

**Architecture:**
- **平台层**新增 `Recorder`：`SCStream` 的采样缓冲直接交给 `AVAssetWriter`。`start_recording` 阻塞到开始录制，`Recorder::stop` 阻塞到文件写完；另有麦克风权限查询与申请、取 NSWindow 编号、生成文件引用剪切板格式。Windows 上同名函数返回 `Unsupported`。
- **应用层**：
  - `shot::begin` 增加模式参数，录屏模式复用冻结、吸附与遮罩，载荷带 `mode: "rec"`。
  - 新模块 `rec.rs` 管理录制：开始、停止、边框窗口 `rec-frame`、菜单栏计时与“停止录制”菜单项、异常中断轮询、出结果后写剪切板和发系统通知。
  - 快捷键从两个变成三个：唤起、截图、录屏，成对注册改成三个一起注册。
- **前端**：遮罩 `src/shot/main.ts` 增加录屏模式（只有声音开关、取消、开始录制，没有标注），按回车后倒计时 3 秒，再调 `rec_start`。设置页“截图”标签加录屏几项（只在 macOS 显示）。

**Tech Stack:** Rust（objc2 0.6、`objc2-screen-capture-kit` 0.3 新增、`objc2-av-foundation` / `objc2-core-media` 0.3 增加特性、`block2`、`dispatch2`）、tauri 2（`set_title` 菜单栏文字、`tauri-plugin-notification`）、TypeScript + Vite（`node:test`）。

**Spec:** [docs/specs/2026-10-28-截图与录屏-设计.md](../specs/2026-10-28-截图与录屏-设计.md)：§2 目标 4 与反目标、§4.6、§4.7 录屏那几行、§6 阶段 13。交互以 [原型](../specs/2026-10-28-截图与录屏-原型.html) 的录屏部分为准，不同之处见下文“对设计的裁定”。规格说明 v0.1.21 → v0.1.22，新增 M24，回写见 Task 6。

**对设计的裁定**（实现与 §4.6 或原型不同的地方，Task 6 写进设计文档 §8）

1. **录完的提示用系统通知**：原型在遮罩里弹带缩略图的提示条，但录完时遮罩早已撤下。为提示条重新上屏一个遮罩代价大，所以改用系统通知，正文用附录文案。
2. **倒计时中按 Esc 直接退出**（原型是回到选区）：与 M23 规则 8“Esc 直接退出”一致。
3. **系统声音、麦克风的选择会记住**：遮罩工具栏上的两个开关与设置里的两项是同一份设置，`rec_start` 时如有改变就写回设置。
4. **同时录系统声音和麦克风时，MP4 里是两条 AAC 音轨**，不做混音。QuickTime 两条一起播；部分播放器只播第一条（系统声音）。写进已知限制。
5. **录制中按截图快捷键不截图**，发通知“正在录屏，停止录制后再截图”：遮罩是普通窗口，会被录进去。
6. **输出尺寸上限**：长边超过 3840 像素时等比缩小，宽高取偶数。5K 屏全屏按 2x 是 5120 × 2880，超出 H.264 编码器的上限，`AVAssetWriter` 会失败。

## Global Constraints

- 只做 macOS（最低 13.0）。Windows 上：
  - 平台层录屏函数返回 `PlatformError::Unsupported`；
  - 录屏快捷键不注册，设置页录屏几行不显示（`os-mac`）；
  - `make lint` 的 Windows 交叉 clippy 保持通过。
- 不为录屏引入 ffmpeg 等大依赖；只加 objc2 系列 crate 与特性。
- 日志不写文件路径、文件名、窗口标题；只记尺寸、帧率、时长、字节数、音轨开关、显示器序号。
- `Settings` 新字段带默认值，旧 JSON 能直接读出，不需要数据库迁移。要同步的地方：`changed_fields`、`src/api/types.ts`、`src/settings-form.ts` 和它们的测试。
- 默认值：

  | 设置字段 | 默认值 |
  | --- | --- |
  | 录屏快捷键 `rec_hotkey` | `Alt+Shift+R`，空字符串表示不启用 |
  | 录屏文件夹 `rec_dir` | 空字符串，表示 `~/Movies/xPaste`；取不到“影片”目录时用 `<数据目录>/recordings` |
  | 录制系统声音 `rec_system_audio` | 关 |
  | 录制麦克风 `rec_microphone` | 关 |
  | 录完复制到剪切板 `rec_copy` | 开 |

- 录屏文件名：`录屏 YYYY-MM-DD HH.MM.mp4`，时间戳用 `xpaste_core::capture::local_stamp`。重名依次加 ` 2`、` 3`（同截图）。
- 录制参数：
  - 帧率 30（`minimumFrameInterval = 1/30 s`），`showsCursor = true`；
  - 视频 H.264（`AVVideoCodecTypeH264`），文件类型 MPEG-4；
  - 音频 AAC，48 kHz、双声道、128 kbps；
  - 输出像素 = 选区逻辑尺寸 × 屏幕缩放，长边不超过 3840，宽高向下取偶数。
- 过滤器：`SCContentFilter initWithDisplay:excludingWindows:`，只排除录制边框窗口。贴图、面板都照常录进去；遮罩在录制开始前已隐藏。
- 麦克风：
  - 只在 macOS 15 及以上可用（`SCStreamConfiguration.captureMicrophone`）；
  - macOS 13–14 上开关不可用，提示“麦克风需要 macOS 15”；
  - `src-tauri/Info.plist` 写 `NSMicrophoneUsageDescription`：“xPaste 录屏时录下麦克风的声音”。
- 倒计时：3 秒，圆环用 `--c-video`，显示“按 Esc 取消”（原型 `.count`）。
- 录制边框：在选区外 3 px 处画 2 px 的 `--c-video` 线，外加辉光（原型 `#recFrame`）。边框窗口鼠标穿透、不抢焦点、被录制过滤器排除。
- 菜单栏：录制中标题为 `● mm:ss`，一小时及以上为 `● h:mm:ss`，每秒更新。菜单第一项插入“停止录制（<录屏快捷键标签>）”，停止后移除，标题清空。
- 文案（Task 6 写进附录）：
  - 录完：`录屏已保存并复制 · mm:ss`；没开“录完复制”时为 `录屏已保存 · mm:ss`。
  - 太短没录到画面：`录屏太短，没有保存`。
  - 录制被系统中断：`录屏中断，已保存录到的部分 · mm:ss`。
  - 录制中按截图快捷键：`正在录屏，停止录制后再截图`。
  - 麦克风权限被拒：`麦克风权限未开启，本次录屏没有麦克风声音`。
  - 权限框标题：`录屏需要屏幕录制权限`。
  - 遮罩提示：`选择录制区域　单击 选中窗口　拖动 框选　F 全屏　Esc 退出`。
- 每个任务结束 `make check` 必须通过，平台层任务还要通过 `make lint`。

## Review Focus

1. **很短的录制**：倒计时结束后马上停止，可能一帧都没收到。此时写入器还没开始会话，`finishWriting` 会失败；不能留下 0 字节或损坏的 mp4，要发“录屏太短，没有保存” → Task 2 `Recorder::stop` 返回 `RecordOutcome::Empty`；Task 3 `outcome_notice` 测试。
2. **大屏全屏录制**：5K、6K 屏全屏 → Task 2 测试 `output_size_caps_long_side_and_rounds_even`。
3. **录制中途被系统停掉**：显示器断开、权限被撤销、休眠，`SCStreamDelegate` 会回报 `didStopWithError`。应用不能一直显示计时，已录的部分要保存 → Task 2 `Recorder::failed()`；Task 3 计时线程每秒轮询，失败按中断处理；验收行。
4. **录制中退出 xPaste**：文件必须写完，否则 mp4 缺 moov、打不开 → Task 3 在退出前同步 `stop`。
5. **连按录屏快捷键或快捷键状态错乱**：
   - 遮罩上屏前、倒计时中、录制中、停止写文件期间再按，都不能开第二次录制，也不能重复停止；
   - 规则：录制中按 = 停止；遮罩在屏上按 = 同截图的 `Press` 规则；停止进行中按 = 忽略。
   → Task 3 `RecState` 测试 `stop_is_idempotent`；Task 5 `rec_route` 测试。
