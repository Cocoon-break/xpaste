## 1. 产品概述

### 1.1 定位

xPaste 是一款常驻后台的剪切板历史工具。它自动记录用户复制过的文本、链接、代码、颜色、图片、视频和文件；用户按下全局快捷键即可唤起面板，搜索、预览并把任意一条历史内容重新粘贴到当前应用。

### 1.2 核心原则

1. **唤起即用**：快捷键按下后面板立即可交互，内容不等动画。
2. **键盘优先**：所有功能都能只用键盘完成。
3. **完全本地**：剪切板数据只存储在本机，不上传、不同步、不联网抓取。
4. **默认保护隐私**：密码管理器等声明为敏感的内容默认不记录。

### 1.3 运行形态

| 组成 | 说明 |
| --- | --- |
| 后台进程 | 开机后常驻，监听剪切板变化并写入本地历史 |
| 面板 | 快捷键唤起的浮动窗口，承载搜索、列表、预览等全部主要功能 |
| 菜单栏 / 托盘图标 | macOS 菜单栏图标、Windows 系统托盘图标，提供暂停、设置、退出等入口〔原型未体现〕 |
| 设置 | 从面板、托盘或快捷键打开 |

### 1.4 目标平台

| 平台 | 最低版本〔建议值〕 | 架构 |
| --- | --- | --- |
| macOS | macOS 13 Ventura 及以上 | Apple Silicon、Intel |
| Windows | Windows 10 21H2 及以上、Windows 11 | x64（ARM64 为 P2） |

## 4. 功能详述

### M01 剪切板采集（P0）

**规则**

1. 监听系统剪切板变化，每次变化生成一条新记录或更新已有记录。
   - macOS：轮询 `NSPasteboard.changeCount`，间隔 300 ms〔建议值〕。
   - Windows：通过 `AddClipboardFormatListener` 接收 `WM_CLIPBOARDUPDATE`。
2. 每条记录保存：剪切板中的全部格式原始数据（用于粘贴时原样还原）、类型、来源应用（名称、图标、macOS bundle ID / Windows 可执行文件路径）、复制时间、大小。
3. 来源应用识别：
   - macOS：取剪切板变化时的前台应用。
   - Windows：优先取剪切板所有者窗口（`GetClipboardOwner`）所属进程；取不到时取前台窗口所属进程。
   - 都取不到时显示“未知来源”。
4. **去重**：新内容与已有记录完全相同（对规范化后的内容取哈希比较）时，不新建记录，而是把该记录的复制时间更新为当前、使用次数 +1。置顶记录只更新使用次数，位置不变。
5. **自身写入不记录**：xPaste 自己写入剪切板（M09 的复制、粘贴）引起的变化，不产生新记录。
6. **敏感内容过滤**（设置项“跳过密码与验证码”，默认开启）：
   - macOS：剪切板包含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType` 或 `org.nspasteboard.AutoGeneratedType` 类型时不记录。
   - Windows：剪切板包含 `ExcludeClipboardContentFromMonitorProcessing` 格式，或 `CanIncludeInClipboardHistory` 值为 0 时不记录。
   - 基于内容识别验证码（如 4–8 位纯数字）为 P2〔待确认〕。
7. **忽略应用**：来源应用在“不记录这些应用”列表中时不记录（M15）。
8. **暂停记录**：用户可从托盘或面板标题栏暂停；暂停期间不产生、不更新任何记录（P0）。
9. **单条大小上限**〔建议值〕：纯文本超过 5 MB、图片数据超过 50 MB 时不记录；文件、视频按引用（路径）记录，不受此限。
10. 同一次复制包含多种格式（如富文本 + 纯文本，或文件引用 + 图片）时全部保存；记录的类型按 M02 判定。

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M01-01 | 在任意应用复制一段文本 | 1 秒内出现在面板列表“今天”分组的第一条，来源应用名称和图标正确 |
| AC-M01-02 | 再次复制同一段文本 | 不出现重复记录；该记录回到“今天”第一条，使用次数 +1 |
| AC-M01-03 | 在 1Password（或任意声明敏感类型的应用）中复制密码 | 不产生记录 |
| AC-M01-04 | 把某应用加入忽略列表后在其中复制；再把它移出后复制 | 加入期间不产生记录；移出后恢复记录 |
| AC-M01-05 | 通过 xPaste 复制或粘贴一条历史记录 | 不产生新记录 |
| AC-M01-06 | 暂停记录后复制内容；恢复后再复制 | 暂停期间无记录；恢复后正常记录 |
| AC-M01-07 | 从 Word（Windows）或备忘录 / Pages（macOS）复制带格式文本，再通过 xPaste 粘贴回原应用 | 粘贴结果保留原格式 |
| AC-M01-08 | 关闭“跳过密码与验证码”后重复 AC-M01-03 | 产生记录 |

### M02 内容类型识别（P0）

按以下顺序判定，命中即停止：

| 顺序 | 条件 | 类型 |
| --- | --- | --- |
| 1 | 剪切板含文件引用，扩展名属于视频扩展名 | 视频 |
| 2 | 剪切板含文件引用，扩展名属于图片扩展名 | 图片 |
| 3 | 剪切板含其他文件引用 | 文件 |
| 4 | 剪切板含位图数据且没有非空白文本（截图、从网页复制图片等）。同时有非空白文本时（如从 Numbers、Pages 复制，位图只是渲染图）按规则 5–8 判定，位图仍保存用于预览 | 图片 |
| 5 | 纯文本去掉首尾空白后匹配 `^#([0-9a-f]{3}\|[0-9a-f]{6})$`（不区分大小写） | 颜色 |
| 6 | 纯文本去掉首尾空白后匹配 `^https?://\S+$` | 链接 |
| 7 | 满足任一：来源是代码编辑器或终端；文本含换行且含 `{ } ; = ( ) < >` 中任一字符；以 `$ `、`git `、`npm `、`pnpm `、`SELECT `、`const `、`let `、`function `、`import ` 开头 | 代码 |
| 8 | 其他文本（含富文本） | 文本 |

- 视频扩展名：`mp4 mov m4v mkv avi webm wmv flv`。
- 图片扩展名：`png jpg jpeg gif webp heic bmp tif tiff svg`。
- 代码编辑器与终端名单（初始）：VS Code、Cursor、JetBrains 系列、Xcode、Sublime Text、终端（Terminal）、iTerm2、Windows Terminal、PowerShell。
- 一次复制多个文件时：全部属于同一类（都是视频或都是图片）则取该类型，否则为“文件”〔待确认〕。
- 代码记录尽量识别语言并显示语言标签（如 JavaScript、Shell、SQL）；识别不出时不显示标签（P1）。
- 颜色扩展支持 `rgb()`、`hsl()`、8 位十六进制为 P2。

**验收标准**

| 编号 | 复制内容 | 预期类型 |
| --- | --- | --- |
| AC-M02-01 | `#6F8BFF`、`#fff` | 颜色 |
| AC-M02-02 | `https://github.com/` | 链接 |
| AC-M02-03 | `见 https://github.com/`（前面有文字） | 文本 |
| AC-M02-04 | 从 VS Code 复制的一行代码 | 代码 |
| AC-M02-05 | `git log --oneline` | 代码 |
| AC-M02-06 | 系统截图（直接存入剪切板） | 图片 |
| AC-M02-07 | 在访达 / 资源管理器中复制一个 `.mp4` 文件 | 视频 |
| AC-M02-08 | 在访达 / 资源管理器中复制一个 `.png` 文件 | 图片 |
| AC-M02-09 | 在访达 / 资源管理器中复制一个 `.fig` 文件 | 文件 |
| AC-M02-10 | 普通中文句子 | 文本 |

### M03 历史存储与清理（P0）

**规则**

1. 数据存储在本机：
   - macOS：`~/Library/Application Support/xPaste/`
   - Windows：`%APPDATA%\xPaste\`
2. 记录元数据和文本存入本地数据库（建议 SQLite）；图片位图另存为 PNG 文件；视频与文件只保存路径，缩略图和视频元数据缓存在本地。
3. **保留时长**：7 天 / 30 天 / 90 天 / 永久，默认 30 天。超过保留时长的记录自动删除，置顶记录除外。启动时检查一次，之后每小时检查一次〔建议值〕。
4. **最多保存条数**：50–5000，默认 500。超出时从最早的非置顶记录开始删除。
5. 修改保留时长或最多条数导致将要删除记录时，先提示“将删除 N 条记录”，用户确认后才执行〔建议值〕。
6. 文件、视频的源文件被移动或删除后：记录保留；预览显示“原文件已移动或删除”；复制 / 粘贴时给出同样提示并中止。
7. 所有写入使用事务；应用崩溃或强制退出后，已写入的记录不丢失。
8. 数据库加密〔待确认〕：建议 P1 使用系统密钥（macOS 钥匙串 / Windows DPAPI）保管密钥并加密数据库。

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M03-01 | 设为“7 天”，将系统时间调后 8 天后重启应用 | 8 天前的非置顶记录被删除，置顶记录保留 |
| AC-M03-02 | 设为最多 50 条，复制第 51 条 | 最早的一条非置顶记录被删除，总数为 50 |
| AC-M03-03 | 复制一个文件后在磁盘上删除它，再在 xPaste 中预览、粘贴 | 预览提示“原文件已移动或删除”；粘贴被中止并提示 |
| AC-M03-04 | 复制若干内容后强制结束进程，再启动 | 之前的记录完整保留 |
| AC-M03-05 | 退出并重启应用 | 历史、置顶、使用次数与退出前一致 |

### M04 面板唤起与窗口（P0）

**规则**

1. 默认全局快捷键：macOS `⌘ ⇧ V`，Windows `Ctrl + Shift + V`〔待确认：与部分应用的“粘贴为纯文本”冲突〕。可在设置中修改。
2. 按下快捷键时：
   - 面板出现在鼠标所在的显示器，水平居中，垂直位于上三分之一处〔建议值〕。
   - 面板浮在所有窗口之上，包括全屏应用之上（macOS 需支持全屏空间）。
   - 焦点进入搜索框，列表选中第一条。
   - 每次唤起清空搜索词；分类保留上一次的选择〔待确认〕。
3. 以下任一情况隐藏面板（不退出应用）：再次按快捷键；搜索框为空时按 Esc；点击面板外部；完成粘贴（M09）；点击标题栏的最小化或关闭按钮。
4. 面板不在 Dock / 任务栏显示独立图标。
5. 尺寸：默认 960 × 640，最小 720 × 520，可拖动调整并记住上次尺寸〔建议值〕。宽度小于 760 时，列表和预览改为上下排列。
6. 标题栏：显示应用名、“剪切板历史”、记录状态徽标（“正在记录” / “已暂停”，点击可切换，P1）、最小化与关闭按钮。
7. 性能：从按下快捷键到面板可输入不超过 100 ms〔建议值〕。

**面板布局（自上而下）**

1. 标题栏
2. 搜索框（右侧显示“匹配数 / 总数”）+ 设置按钮
3. 复制频谱（M14）
4. 分类筛选栏（M06）
5. 主体：左侧历史列表（M07），右侧预览（M08）
6. 状态栏：左侧显示当前选中项；右侧显示常用快捷键提示

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M04-01 | 在任意应用中按唤起快捷键 | 面板出现在鼠标所在显示器，搜索框获得焦点，第一条被选中 |
| AC-M04-02 | 在全屏应用中按唤起快捷键 | 面板显示在全屏应用之上 |
| AC-M04-03 | 面板打开时，分别按快捷键、按 Esc、点击面板外部 | 每种操作都使面板隐藏，应用仍在后台运行 |
| AC-M04-04 | 搜索框有内容时按 Esc | 先清空搜索框，面板不隐藏；再按 Esc 才隐藏 |
| AC-M04-05 | 调整面板尺寸后隐藏，再唤起 | 保持调整后的尺寸 |
| AC-M04-06 | 双显示器，鼠标分别放在两块屏幕上唤起 | 面板出现在鼠标所在屏幕 |
| AC-M04-07 | 用高速摄像或性能埋点测量唤起耗时 | 不超过 100 ms |

### M05 搜索（P0）

**规则**

1. 实时过滤：每次输入后立即更新列表，不需要按回车。
2. 匹配范围：文本内容、链接标题与 URL、图片 / 视频 / 文件的文件名与路径、来源应用名称。
3. 不区分大小写的子串匹配。
4. 列表标题中的匹配部分高亮显示。
5. 搜索与分类筛选叠加生效。
6. 搜索框右侧显示“匹配数 / 总数”，数字变化时有轻微切换动效（M20）。
7. 输入法组字过程中（拼音未上屏）不触发过滤，上屏后再过滤。
8. 搜索框有内容时显示清除按钮。
9. 无结果时显示：“没有匹配“关键词”的〔分类名〕记录”，以及“清除搜索与筛选”按钮。
10. 面板打开、焦点不在搜索框时，直接输入字符会自动进入搜索框。
11. 拼音 / 首字母搜索为 P2。
12. 性能：5000 条记录下，从输入到列表更新不超过 50 ms〔建议值〕。

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M05-01 | 输入“会议” | 只显示内容含“会议”的记录，“会议”高亮，计数正确 |
| AC-M05-02 | 输入“figma” | 显示来源为 Figma 的记录 |
| AC-M05-03 | 用拼音输入法输入“huiyi”但未上屏 | 列表不变化；上屏“会议”后才过滤 |
| AC-M05-04 | 选中“代码”分类后输入“git” | 只显示类型为代码且含 git 的记录 |
| AC-M05-05 | 输入不存在的词 | 显示无结果提示与“清除搜索与筛选”按钮，点击后恢复全部 |
| AC-M05-06 | 在 5000 条数据下连续输入 | 每次更新不超过 50 ms，无卡顿 |

### M06 分类筛选（P0）

**规则**

1. 分类顺序：全部、常用 ｜ 文本、链接、代码、颜色、图片、视频、文件。“常用”与类型分类之间用分隔线隔开。
2. 每个分类显示记录数量；“常用”显示达到常用阈值的记录数。

### M09 复制与粘贴（P0）

**触发方式**：Enter；双击列表行；预览区“复制”按钮；行悬停的“复制”快捷按钮；右键菜单“复制”；`Mod + 1–9`（复制当前列表中对应序号的记录）。

**行为**〔待确认，见问题 Q1〕

1. 把记录的全部原始格式写回剪切板：文本、富文本还原原格式；图片写回为位图；文件、视频、图片文件写回为文件引用，可在访达 / 资源管理器中粘贴为文件。
2. 隐藏面板，焦点回到唤起面板前的应用。

### M20 动效（P1；“减少动态效果”适配为 P0）

**原则**

1. 内容永远即时可用，动效只负责说明“发生了什么、去了哪里”。
2. 键盘触发的高频操作不加或只加极短的动效；按住方向键连续移动时关闭过渡。
3. 系统开启“减少动态效果”时，全部动效降为即时切换：macOS 读取“减弱动态效果”设置，Windows 读取“显示动画效果”设置（P0）。
4. 动效只改变位移、缩放、透明度和少量模糊，不改变布局尺寸（行高展开 / 收起除外）。

**曲线**

| 名称 | 值 | 用途 |
| --- | --- | --- |
| enter | `cubic-bezier(0.22, 1, 0.36, 1)` | 进入、展开 |
| move | `cubic-bezier(0.25, 1, 0.5, 1)` | 位移、滑动 |
| spring | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 带回弹的落位 |

**动效清单**

| 交互 | 时长 | 曲线 | 表现 |
| --- | --- | --- | --- |
| 首次打开面板 | 720 ms | enter / spring | 面板上浮缩放 → 频谱光柱从左到右依次升起（间隔 18 ms）→ 列表逐行浮现（间隔 28 ms） |
| 快捷键唤起 / 隐藏 | 90 / 160 ms | enter / ease-out | 几乎即时出现；隐藏时短暂淡出 |
| 选中项切换 | 130 ms | move | 高亮框滑到目标行并换成该类型色；按住方向键时 0 ms |
| 预览切换 | 180 ms | enter | 新内容从下方 4 px 带轻微模糊浮入；按住方向键时跳过 |
| 频谱游标 | 360 ms | move | 游标滑到选中记录的时间位置 |
| 切换分类 | 380 ms | enter | 指示条滑到目标分类并换色，列表逐行浮现；用键盘切换时 0 ms |
| 新记录进入 | 300 / 520 ms | enter / spring | 行高展开推开下方记录 → 新行弹性落位 → 类型色闪光；频谱长出新光柱并脉冲 |
| 复制成功 | 760 ms | move | 一道类型色光扫过该行；复制按钮图标弹性变为对勾 |
| 删除 | 180 + 240 ms | ease-out / move | 先向左滑出并模糊，100 ms 后收起行高；撤销按钮带 5 秒倒计时圈 |
| 置顶（鼠标） | 300 ms | move | 行平移到“置顶”分组，高亮框同步跟随；图钉旋转弹入 |
| 右键菜单 | 260 / 120 ms | spring / ease-out | 从指针所在角展开，菜单项间隔 24 ms 依次落位 |
| 设置对话框 | 420 / 150 ms | spring / ease-out | 居中弹入，表单分组间隔 45 ms 依次浮现；开关滑块带回弹 |
| 悬停 | 0 / 140 ms | ease-out | 行背景立即出现、缓慢消失；快捷按钮从右侧滑入；视频封面播放按钮放大 |
| 提示条 | 420 / 160 ms | spring / ease-out | 从下方弹入、向下退出；连续触发时更新文字，不重新播放 |

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M20-01 | 开启系统“减少动态效果”后重复本节所有交互 | 无位移、缩放、弹性动画，状态即时切换 |

## 5. 非功能需求

### 5.1 性能〔均为建议值〕

| 指标 | 目标 |
| --- | --- |
| 冷启动到开始记录 | ≤ 2 秒 |
| 唤起面板到可输入 | ≤ 100 ms |
| 复制到出现在历史中 | ≤ 1 秒 |
| 搜索更新（5000 条） | ≤ 50 ms |
| 后台空闲 CPU | < 1% |
| 后台常驻内存 | ≤ 150 MB |

### 5.2 隐私与安全

1. 剪切板数据只存在本机，不上传、不同步。
2. 除检查更新外不发起任何网络请求〔待确认，见 Q6〕；不收集使用统计。
3. 日志中不得写入剪切板内容。
4. 卸载时询问是否同时删除历史数据。

### 5.3 可靠性

1. 读取剪切板失败（被其他程序占用等）时跳过本次，不影响后续记录。
2. 快捷键注册失败时，通过托盘通知用户并引导到设置修改。
3. 应用崩溃后自动恢复（开机启动项保持）；已写入数据不丢失。

### 5.4 兼容性

1. 支持多显示器、不同缩放比例（100%–200%），文字和图标清晰。
2. 支持 macOS 全屏空间、Windows 虚拟桌面。
3. 支持系统深浅色、系统强调色不影响 xPaste 配色。

### 5.5 安装、更新与卸载

1. macOS：签名并公证的 `.dmg`。
2. Windows：签名的安装包（`.exe` 或 `.msix`），支持当前用户安装（不需要管理员权限）。
3. 自动更新〔待确认〕。

### 5.6 文案与语言

1. 首版仅简体中文；日期、时间、数字按系统区域格式化。
2. 术语统一：记录、置顶、常用、复制、粘贴、来源应用（见第 2 章）。
3. 按钮写明动作结果（“保存设置”“清除搜索与筛选”）；提示条与触发它的按钮用同一个动词（“删除” → “已删除”）。
4. 错误提示说明发生了什么、怎么解决，不使用“出错了”之类的模糊说法。

## 6. 平台差异汇总

| 能力 | macOS | Windows |
| --- | --- | --- |
| 监听剪切板 | 轮询 `NSPasteboard.changeCount` | `AddClipboardFormatListener` |

| 安装包 | 签名并公证的 `.dmg` | 签名的 `.exe` / `.msix` |
