## 1. 产品概述

### 1.1 定位

xPaste 是一款常驻后台的剪切板历史工具。它自动记录用户复制过的文本、链接、代码、图片、视频和文件；用户按下全局快捷键即可唤起面板，搜索、预览并把任意一条历史内容重新粘贴到当前应用。

### 1.2 核心原则

1. **唤起即用**：快捷键按下后面板立即可交互，内容不等动画。
2. **键盘优先**：所有功能都能只用键盘完成。
3. **完全本地**：剪切板数据只存储在本机，不上传、不同步、不联网抓取。
4. **默认保护隐私**：密码管理器等声明为敏感的内容默认不记录。

### 1.3 运行形态

| 组成 | 说明 |
| --- | --- |
| 后台进程 | 开机后常驻，监听剪切板变化并写入本地历史 |
| 面板 | 快捷键唤起的浮动窗口，承载搜索、列表、预览等全部主要功能 |
| 菜单栏 / 托盘图标 | macOS 菜单栏图标、Windows 系统托盘图标，提供暂停、设置、退出等入口〔原型未体现〕 |
| 设置 | 从面板、托盘或快捷键打开 |

### 1.4 目标平台

| 平台 | 最低版本〔建议值〕 | 架构 |
| --- | --- | --- |
| macOS | macOS 13 Ventura 及以上 | Apple Silicon、Intel |
| Windows | Windows 10 21H2 及以上、Windows 11 | x64（ARM64 为 P2） |

## 4. 功能详述

### M01 剪切板采集（P0）

**规则**

1. 监听系统剪切板变化，每次变化生成一条新记录或更新已有记录。
   - macOS：轮询 `NSPasteboard.changeCount`，间隔 300 ms〔建议值〕。
   - Windows：通过 `AddClipboardFormatListener` 接收 `WM_CLIPBOARDUPDATE`。
2. 每条记录保存：剪切板中的全部格式原始数据（用于粘贴时原样还原）、类型、来源应用（名称、图标、macOS bundle ID / Windows 可执行文件路径）、复制时间、大小。
3. 来源应用识别：
   - macOS：取剪切板变化时的前台应用。
   - Windows：优先取剪切板所有者窗口（`GetClipboardOwner`）所属进程；取不到时取前台窗口所属进程。
   - 都取不到时显示“未知来源”。
4. **去重**：新内容与已有记录完全相同（对规范化后的内容取哈希比较）时，不新建记录，而是把该记录的复制时间更新为当前、使用次数 +1。置顶记录只更新使用次数，位置不变。
5. **自身写入不记录**：xPaste 自己写入剪切板（M09 的复制、粘贴）引起的变化，不产生新记录。例外：截图与贴图的“复制”“保存并复制”（M23）按普通写入，像其他截图一样产生新记录；截图的“识别文字”也按普通写入，识别出的文字作为一条文本记录入库。录屏录完复制（M24）同样按普通写入，视频文件作为一条视频记录入库。
6. **敏感内容过滤**（设置项“跳过密码管理器与敏感内容”，默认开启）：
   - macOS：剪切板包含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType` 或 `org.nspasteboard.AutoGeneratedType` 类型时不记录。
   - Windows：剪切板包含 `ExcludeClipboardContentFromMonitorProcessing` 格式，或 `CanIncludeInClipboardHistory` 值为 0 时不记录。
   - 基于内容识别验证码（如 4–8 位纯数字）为 P2〔待确认〕。
7. **忽略应用**：来源应用在“不记录这些应用”列表中时不记录（M15）。
8. **暂停记录**：用户可从托盘或面板标题栏暂停；暂停期间不产生、不更新任何记录（P0）。暂停状态跨重启保留：退出或重启后仍是暂停，直到用户点“继续记录”。
9. **单条大小上限**〔建议值〕：纯文本超过 5 MB、图片数据超过 50 MB 时不记录；文件、视频按引用（路径）记录，不受此限。
10. 同一次复制包含多种格式（如富文本 + 纯文本，或文件引用 + 图片）时全部保存；记录的类型按 M02 判定。

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M01-01 | 在任意应用复制一段文本 | 1 秒内出现在面板列表“今天”分组的第一条，来源应用名称和图标正确 |
| AC-M01-02 | 再次复制同一段文本 | 不出现重复记录；该记录回到“今天”第一条，使用次数 +1 |
| AC-M01-03 | 在 1Password（或任意声明敏感类型的应用）中复制密码 | 不产生记录 |
| AC-M01-04 | 把某应用加入忽略列表后在其中复制；再把它移出后复制 | 加入期间不产生记录；移出后恢复记录 |
| AC-M01-05 | 通过 xPaste 复制或粘贴一条历史记录 | 不产生新记录 |
| AC-M01-06 | 暂停记录后复制内容；恢复后再复制 | 暂停期间无记录；恢复后正常记录 |
| AC-M01-07 | 从 Word（Windows）或备忘录 / Pages（macOS）复制带格式文本，再通过 xPaste 粘贴回原应用 | 粘贴结果保留原格式 |
| AC-M01-08 | 关闭“跳过密码管理器与敏感内容”后重复 AC-M01-03 | 产生记录 |

### M02 内容类型识别（P0）

按以下顺序判定，命中即停止：

| 顺序 | 条件 | 类型 |
| --- | --- | --- |
| 1 | 剪切板含文件引用，扩展名属于视频扩展名 | 视频 |
| 2 | 剪切板含文件引用，扩展名属于图片扩展名 | 图片 |
| 3 | 剪切板含其他文件引用 | 文件 |
| 4 | 剪切板含位图数据且没有非空白文本（截图、从网页复制图片等）。同时有非空白文本时（如从 Numbers、Pages 复制，位图只是渲染图）按规则 5–7 判定，位图仍保存用于预览 | 图片 |
| 5 | 纯文本去掉首尾空白后匹配 `^https?://\S+$` | 链接 |
| 6 | 满足任一：来源是代码编辑器或终端；文本含换行且含 `{ } ; = ( ) < >` 中任一字符；以 `$ `、`git `、`npm `、`pnpm `、`SELECT `、`const `、`let `、`function `、`import ` 开头 | 代码 |
| 7 | 其他文本（含富文本）。`#6F8BFF` 这类颜色值也按本表判定（阶段 9 删除了颜色类型，见第 8 章） | 文本 |

- 视频扩展名：`mp4 mov m4v mkv avi webm wmv flv`。
- 图片扩展名：`png jpg jpeg gif webp heic bmp tif tiff svg`。
- 代码编辑器与终端名单（初始）：VS Code、Cursor、JetBrains 系列、Xcode、Sublime Text、终端（Terminal）、iTerm2、Windows Terminal、PowerShell。
- 一次复制多个文件时：全部属于同一类（都是视频或都是图片）则取该类型，否则为“文件”〔待确认〕。
- 文件引用都不可用且同时有位图时，忽略文件引用，按规则 4 判为图片，预览与文字识别用位图（本期 macOS）。不可用指打不开，或位于其他应用的沙盒容器（`~/Library/Containers/`、`~/Library/Group Containers/`）里：如微信复制图片时附带的是它容器里的临时文件，无权读取、很快被删除；容器里的路径不去打开，以免弹出“访问其他应用的数据”授权框。这时记录不保留文件引用，粘贴时只写回图片。
- 代码记录尽量识别语言并显示语言标签（如 JavaScript、Shell、SQL）；识别不出时不显示标签（P1）。

**验收标准**

| 编号 | 复制内容 | 预期类型 |
| --- | --- | --- |
| AC-M02-01 | 从普通应用（非代码编辑器）复制 `#6F8BFF`、`#fff` | 文本（从代码编辑器复制时为代码） |
| AC-M02-02 | `https://github.com/` | 链接 |
| AC-M02-03 | `见 https://github.com/`（前面有文字） | 文本 |
| AC-M02-04 | 从 VS Code 复制的一行代码 | 代码 |
| AC-M02-05 | `git log --oneline` | 代码 |
| AC-M02-06 | 系统截图（直接存入剪切板） | 图片 |
| AC-M02-07 | 在访达 / 资源管理器中复制一个 `.mp4` 文件 | 视频 |
| AC-M02-08 | 在访达 / 资源管理器中复制一个 `.png` 文件 | 图片 |
| AC-M02-09 | 在访达 / 资源管理器中复制一个 `.fig` 文件 | 文件 |
| AC-M02-10 | 普通中文句子 | 文本 |
| AC-M02-11 | 在微信（macOS）聊天里右键复制一张图片 | 图片，预览与缩略图正常、可以识别文字 |

### M03 历史存储与清理（P0）

**规则**

1. 数据存储在本机：
   - macOS：`~/Library/Application Support/xPaste/`
   - Windows：`%APPDATA%\xPaste\`
2. 记录元数据和文本存入本地数据库（建议 SQLite）；图片位图另存为 PNG 文件；视频与文件只保存路径，缩略图和视频元数据缓存在本地。
3. **保留时长**：7 天 / 30 天 / 90 天 / 永久，默认 30 天。超过保留时长的记录自动删除，置顶记录除外。启动时检查一次，之后每小时检查一次〔建议值〕。
4. **最多保存条数**：50–5000，默认 500。超出时从最早的非置顶记录开始删除。
5. 修改保留时长或最多条数导致将要删除记录时，先提示“将删除 N 条记录”，用户确认后才执行〔建议值〕。
6. 文件、视频的源文件被移动或删除后：记录保留；预览显示“原文件已移动或删除”；复制 / 粘贴时给出同样提示并中止。
7. 所有写入使用事务；应用崩溃或强制退出后，已写入的记录不丢失。
8. 数据库加密〔待确认〕：建议 P1 使用系统密钥（macOS 钥匙串 / Windows DPAPI）保管密钥并加密数据库。

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M03-01 | 设为“7 天”，将系统时间调后 8 天后重启应用 | 8 天前的非置顶记录被删除，置顶记录保留 |
| AC-M03-02 | 设为最多 50 条，复制第 51 条 | 最早的一条非置顶记录被删除，总数为 50 |
| AC-M03-03 | 复制一个文件后在磁盘上删除它，再在 xPaste 中预览、粘贴 | 预览提示“原文件已移动或删除”；粘贴被中止并提示 |
| AC-M03-04 | 复制若干内容后强制结束进程，再启动 | 之前的记录完整保留 |
| AC-M03-05 | 退出并重启应用 | 历史、置顶、使用次数与退出前一致 |

### M04 面板唤起与窗口（P0）

**规则**

1. 默认全局快捷键：macOS `⌘ ⇧ V`，Windows `Ctrl + Shift + V`〔待确认：与部分应用的“粘贴为纯文本”冲突〕。可在设置中修改。
2. 按下快捷键时：
   - 面板出现在鼠标所在的显示器，水平居中，垂直位于上三分之一处〔建议值〕。拖动面板只在本次显示有效，下次唤起仍按鼠标所在屏幕定位。
   - 面板浮在所有窗口之上，包括全屏应用之上（macOS 需支持全屏空间）。
   - 焦点进入搜索框，列表选中第一条。
   - 每次唤起清空搜索词；分类保留上一次的选择〔待确认〕。
3. 以下任一情况隐藏面板（不退出应用）：再次按快捷键；搜索框为空时按 Esc；点击面板外部；完成粘贴（M09）。设置或确认对话框打开时，点击面板外部（切到其他应用）和再次按快捷键都不隐藏面板，对话框与未保存的修改保留；对话框打开且面板失焦时按快捷键回到面板（取得焦点），不隐藏；对话框在面板失焦之后才关闭时，关闭即隐藏面板。首次引导不属于这种对话框，失焦照常隐藏。
4. 面板不在 Dock / 任务栏显示独立图标。
5. 尺寸：默认 960 × 640，最小 720 × 520，可拖动调整并记住上次尺寸〔建议值〕。宽度小于 760 时，列表和预览改为上下排列。
6. 标题栏：显示应用名、“剪切板历史”、记录状态徽标（“正在记录” / “已暂停”，点击可切换，P1），靠右。没有最小化、关闭按钮：隐藏面板用规则 3 的方式。
7. 性能：从按下快捷键到面板可输入不超过 100 ms〔建议值〕。

**面板布局（自上而下）**

1. 标题栏
2. 搜索框（右侧显示“匹配数 / 总数”）+ 设置按钮
3. 复制频谱（M14，可收起，见规则 9）
4. 分类筛选栏（M06）
5. 主体：左侧历史列表（M07），右侧预览（M08）
6. 状态栏：左侧显示当前选中项；右侧显示常用快捷键提示

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M04-01 | 在任意应用中按唤起快捷键 | 面板出现在鼠标所在显示器，搜索框获得焦点，第一条被选中 |
| AC-M04-02 | 在全屏应用中按唤起快捷键 | 面板显示在全屏应用之上 |
| AC-M04-03 | 面板打开时，分别按快捷键、按 Esc、点击面板外部 | 每种操作都使面板隐藏，应用仍在后台运行 |
| AC-M04-04 | 搜索框有内容时按 Esc | 先清空搜索框，面板不隐藏；再按 Esc 才隐藏 |
| AC-M04-05 | 调整面板尺寸后隐藏，再唤起 | 保持调整后的尺寸 |
| AC-M04-06 | 双显示器，鼠标分别放在两块屏幕上唤起 | 面板出现在鼠标所在屏幕 |

### M05 搜索（P0）

**规则**

1. 实时过滤：每次输入后立即更新列表，不需要按回车。连续快速输入时，80 ms 内的多次输入合并为一次查询，上一次查询未返回时新输入等它返回后再查，最终列表总是对应最后的输入。
2. 匹配范围：文本内容、链接标题与 URL、图片 / 视频 / 文件的文件名与路径、记录标题（含截图的自动标题“截图 YYYY-MM-DD HH.MM.png”，本地时间）、来源应用名称、图片中的文字（M22，本机识别；含文件记录里夹带的图片）、文件记录中文本类文件的内容（需打开设置“搜索文本文件内容”，默认关，M15；按扩展名判定：`txt`、`md`、`csv`、`json`、`yaml`、`xml`、`html`、常见代码与脚本、`log`、`ini` 等；每条记录按文件顺序最多读入 64 KB，二进制与无扩展名的文件不读；复制时读一次，之后文件改动不再更新；内容只用于搜索，不显示）。命中来自图中文字而标题不含关键词时，列表行显示命中片段（M07 规则 3）。
3. 不区分大小写的子串匹配。
4. 列表标题中的匹配部分高亮显示。
5. 搜索与分类筛选叠加生效。
6. 搜索框右侧显示“匹配数 / 总数”，数字变化时有轻微切换动效（M20）。
7. 输入法组字过程中（拼音未上屏）不触发过滤，上屏后再过滤。
8. 搜索框有内容时显示清除按钮。
9. 无结果时显示：“没有匹配“关键词”的〔分类名〕记录”，以及“清除搜索与筛选”按钮。
10. 面板打开、焦点不在搜索框时，直接输入字符会自动进入搜索框。
11. 拼音与首字母搜索：关键词全是 ASCII 字母且不少于 2 个时，除字面匹配外，还按汉字的拼音匹配，不区分大小写；ü 按输入法习惯打 v（`lvyou` 找“旅游”，`nv` 找“女”）。
    - 正好 2 个字母：只按记录标题（第一行）各字的拼音首字母匹配，所以 `hy` 能找到标题里有“会议”的记录，正文里才有“会议”的记录不算。
    - 3 个及以上字母：在全文里按全拼（如 `yinhang`）或首字母（如 `zsyh`）匹配。全拼必须从音节开头起，最后一个音节可以只打一半：`huiy` 能找到“会议”，`uiyi` 找不到；`ing` 不是任何音节的开头，不会命中中文；`ang` 只从音节开头命中，例如“昂”，或“安”后接 g 开头的字（如“安国”）；`hang` 也不会再命中“上海”（上 shang 的中间不算开头）。输入有歧义时各种切法都算，如 `xian` 同时找到“先”和“西安”。
    - 多音字按附近汉字的其他读音也能命中（`yinhang` 能找到“银行”，`zsyh` 与 `zhaoshangyinhang` 都能找到“招商银行”）；一个词里两个多音字都要换读音时可能找不到，例如用 `cqyh` 找“重庆银行”。
    - 每条记录只取前 4096 个字符生成拼音；匹配不跨过非汉字。
    - 命中来自拼音时，只有标题自身按拼音命中才高亮，高亮的是标题内命中的汉字，而不是输入的字母；只在正文命中时不高亮，与字面命中正文一样（图中文字命中时照常在命中片段里高亮）。
    - 不含汉字的记录只按字面匹配；短英文关键词（如 `js`）也可能按首字母命中中文标题，字面命中照常保留。
    - 拼音索引让数据库变大：中英混合文本约多 50%，中文为主的文本约多 60% 至 80%，每条记录以前 4096 个字符为上限。
    - 需关掉输入法或切到英文模式输入字母（规则 7 不变），没有设置开关。
12. 性能：从输入到列表更新不超过 50 ms〔建议值〕。3 个字符及以上的关键词走本地全文索引，耗时与命中数相关、与历史文本总量基本无关（实测 400 MB 文本未命中 < 1 ms）；1–2 个字符的关键词（如两字中文词）仍顺序扫描，耗时与文本总量线性相关（约 1.6 ms / MB），文本总量过大时可能超过 50 ms，此时规则 1 的合并保证不会越输越慢。2 个字母的关键词另逐条比对标题的拼音首字母（5000 条实测约 8 ms）。3 个及以上字母的拼音关键词在 5000 条上限、中文密集的文本上约 16–29 ms（如 `yinhang` 16 ms、`zhaoshangyinhang` 28 ms、`xian` 29 ms），在 50 ms 目标内；1 万条时约 57 ms。索引使数据库文件约增大一半。

### M14 复制频谱（P1）

面板顶部的时间轴，展示过去 24 小时的复制分布，是 xPaste 的标志性元素。

**规则**

1. 横轴：左侧 6% 宽度为“更早”区（1–7 天前的记录压缩显示在此）；其余 94% 映射过去 24 小时，最右端为“现在”。
2. 刻度：“更早”、18 小时前、12 小时前、6 小时前（显示为具体时刻，如 04:27）、“现在”。“现在”位置有一个持续的脉冲点。放大后（规则 10）主刻度显示 `HH:mm`，次刻度是 4 px 高的小竖线；步长按窗口长度选，主刻度不超过 8 个（如 10 分钟窗口为 2 分钟 / 30 秒，1 小时窗口为 10 分钟 / 2 分钟），落在本地时间的整分钟 / 整小时上。窗口右端贴着“现在”时才有“现在”刻度和脉冲点；离“现在”不到 6% 的主刻度不写时刻，画成次刻度，免得文字重叠。
3. 每条记录对应一根光柱：位置为复制时间，颜色为类型色，高度按内容大小的对数映射（最低 16%，最高 100%）。密度超过每 2 px 一条时，同一像素列的记录合并为一根光柱，代表记录优先取当前筛选命中的那条。合并了多于一条记录的光柱宽 4 px（单条 3 px），顶端有一个小圆点；悬停时提示在相对时间后追加“等 N 条 · 放大可分开”。
4. 当前选中记录的光柱高亮，并有一道光束指向它：颜色取选中记录的类型色，从轨道上方贯穿轨道与倒影（规则 11）；选中记录在频谱上没有位置（超过 7 天，或放大后在窗口之外）时光束隐藏。不符合当前搜索 / 分类的光柱变暗。
5. 鼠标悬停光柱：显示提示（类型色块、标题、相对时间）。
6. 点击光柱：选中对应记录；该记录被当前筛选隐藏时，先清除搜索并切换到“全部”。
7. 右上角统计：“24 小时内复制 N 次”；若某个小时的复制次数大于 1，追加“最忙 H 点（M 次）”。
8. 频谱只是辅助浏览的方式，读屏软件跳过光柱（列表已提供同样信息）；收起 / 展开按钮照常朗读（规则 9）。
9. **收起 / 展开**：标题行右侧有一个箭头按钮，点按钮或点标题行都能切换。收起后只留标题行（说明文字与右上角统计，统计照常更新），光柱、倒影、光束、刻度、预设按钮和概览条隐藏，列表多出约 100 px（阶段 11 加倒影与概览条之前约 70 px）。状态写入设置，跨唤起和重启保留；默认展开。按钮的读屏名称随状态为“收起复制频谱” / “展开复制频谱”。切换即时完成，只有箭头旋转（140 ms，M20 原则 4：不对高度做过渡）。用键盘（Tab 聚焦后按空格 / 回车）切换时箭头同样旋转 140 ms：这是 M20 原则 2 允许的极短动效，作为“键盘触发不加动画”的例外在 M20 动效清单中列出。
10. **时间缩放**（阶段 11）：频谱可以放大到过去 24 小时内的一段时间窗口（下称窗口），挤在一起的光柱拉开后可以单独悬停、点选。缩放只改变频谱的视野，列表、计数、搜索与分类都不受影响。
    - 手势（只在轨道上）：竖向滚轮或触控板捏合，围绕指针所在的时间缩放；已放大时横向滚动或按住拖动平移（移动超过 2 px 才算拖动，松开后不触发点击，拖动中光标为抓手）；双击轨道回到 24 小时。轨道上的滚轮不滚动列表。缩放与拖动即时跟手，没有缓动。
    - 窗口长度 5 分钟 – 24 小时，不超出过去 24 小时，碰到边界时整体贴边；缩到 24 小时即回到默认视图（“更早”区与 6% 处的分隔线只在默认视图出现，放大后不能放进“更早”区）。
    - 右端贴着“现在”的窗口随时间往右走，显示“现在”刻度与脉冲点，面板打开时新复制的记录落在右端并长出光柱；离开“现在”的窗口是固定的时间段，不跟随新记录（新记录只在概览条上多一根竖线），随时间流逝碰到 24 小时左边界时被推着贴边。
    - 标题行：放大后说明文字换成窗口范围，如 `13:04 – 14:04（1 小时）`、`14:02 – 14:12（10 分钟）`；右上角统计不变（仍是 24 小时）。说明文字与统计之间有预设 `24h` `6h` `1h` `10m`：有 24 小时内的选中记录时以它为中心，否则贴着“现在”；当前窗口长度等于预设时该预设高亮（24 小时视图时 `24h` 高亮）；点预设不收起频谱；预设不进入 Tab 顺序。
    - 概览条：放大后刻度行下方出现一条 8 px 高的圆角条，底色为类型色渐变，24 小时内每条记录一根淡竖线，当前窗口用亮框标出；点它把窗口中心挪到点击处。24 小时视图下淡出，不响应点击。
    - 与选中项的关系：用方向键、数字键、点列表行（含右键）或点光柱选中的记录在窗口之外、但在 24 小时内时，窗口平移到以它为中心，长度不变（方向键、数字键即时，鼠标 360 ms）；删除失败后重新选中原记录同样平移。搜索后自动选中第一条、新记录进入、删除后顺延选中、撤销删除后的恢复选中都**不**平移窗口。选中记录在 24 小时之外时窗口不动，光束隐藏。
    - 不记忆：面板隐藏或收起频谱后回到 24 小时。
11. **霓光镜面**（阶段 11）：光柱自下而上从半透明类型色过渡到类型色，顶端发白（亮色主题为 40% 类型色混白），带两层类型色光晕（模糊半径暗色 10 / 24 px，亮色 6 / 14 px）；轨道底部叠一层淡蓝底光。轨道正下方有一层 22 px 高的倒影：每根光柱在同一列满高镜像、向下淡出，不响应指针，不播升起、脉冲与高亮。选中光束 1 px 宽，从轨道顶上 10 px 贯穿到倒影底部，带类型色光晕。频谱块因倒影（22 px）与概览条（10 px，24 小时视图下透明但占位）增高 32 px，列表可见行数最多少 1 行。

**验收标准**

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| AC-M14-01 | 准备不同时间、类型、大小的记录 | 光柱的位置、颜色、相对高度符合规则 |

**交互规则**

1. 设置以对话框形式显示在面板上方；从托盘打开时，先唤起面板再显示设置。
2. “保存设置”后立即生效，提示“设置已保存”；“取消”、Esc、点击遮罩均关闭且不保存。外观点选时已经保存，不受关闭方式影响。
3. 快捷键录制框获得焦点时，提示“请按下组合键，至少包含一个修饰键…”；记录成功后提示“已记录，保存后生效”。录制框聚焦时按下全局唤起快捷键，只把这组快捷键写入录制框，不隐藏面板。设置或确认对话框打开且面板有焦点时按截图快捷键，不开始截图：截图快捷键录制框聚焦时把这组快捷键写入录制框，唤起快捷键录制框聚焦时提示“不能与截图快捷键相同”，其余情况不响应；截图快捷键录制框聚焦时按唤起快捷键，提示“截图快捷键不能与唤起快捷键相同”。录屏快捷键（macOS，M24）同理：按录屏快捷键时，录屏录制框聚焦则写入录屏录制框，唤起录制框聚焦提示“不能与录屏快捷键相同”，截图录制框聚焦提示“截图快捷键不能与录屏快捷键相同”；录屏录制框聚焦时按截图快捷键提示“录屏快捷键不能与截图快捷键相同”，按唤起快捷键提示“录屏快捷键不能与唤起快捷键相同”。
4. 设置或确认对话框打开时，切到其他应用（面板失焦）或按唤起快捷键都不隐藏面板，未保存的修改保留（M04 规则 3）；截图、录屏快捷键同样不开始截图或录屏、不隐藏面板（录制中按录屏快捷键仍是停止录制，M24 规则 1）。对话框打开且面板失焦时按唤起、截图或录屏快捷键只回到面板（取得焦点），不隐藏，也不写入录制框；用户切走之后才关闭对话框时，面板随之隐藏。
5. 设置按功能分为四个标签：通用、记录、搜索、截图（各项所在标签见上表“标签”列），标签栏在对话框标题下方，打开即可定位，不需要滚动查找。
   - 对话框高度固定为四个标签中内容最高的那个，切换标签时不跳动；窗口太矮时只有标签内容区滚动，标题、标签栏和底部按钮始终可见。
   - 打开设置时显示本次运行中上次停留的标签，首次打开为“通用”；只在内存里记，不写入设置。打开时“通用”聚焦唤起快捷键录制框，其他标签聚焦标签本身。

   - “保存设置”一次保存所有标签的改动。保存时校验失败、快捷键被占用或截图、录屏文件夹出错：出错项所在标签右上角显示红点，自动切到（按标签顺序）第一个出错的标签并聚焦出错的控件；改正后红点随行内错误一起消失（数字项输入合法值时即清除）。
   - 设置开着时从托盘“清空历史…”：先切到“记录”标签，结果写在“历史记录”行内。

2. macOS 新版本系统对应用读取剪切板增加了隐私提示，需要在开发初期验证对后台监听的影响，并在引导中说明〔待确认，需技术验证〕。
3. 权限状态在设置中可随时查看和补授（M15）。
4. 屏幕录制权限（仅 macOS，截图与录屏需要，见 M23、M24）：不放进首次引导，不用截图的人不需要它。每次按截图或录屏快捷键时检查，没有权限时不显示遮罩，而是唤起面板并弹出确认框“截图需要屏幕录制权限”（按的是录屏快捷键时为“录屏需要屏幕录制权限”），正文写明到系统设置的哪一页打开 xPaste、再退出并重新打开 xPaste（页名 macOS 15 起为“录屏与系统录音”，之前为“屏幕录制”；文案见附录），按钮“以后再说” / “前往授权”。“前往授权”出现系统授权对话框（首次）并打开系统设置的对应页，同时隐藏面板。系统要求授权后重新打开应用才生效；macOS 15 起系统会定期再次询问是否继续允许。Windows 不需要此权限。
5. 麦克风权限（仅 macOS 15 及以上，录屏开着“录制麦克风”时需要，见 M24 规则 6）：不放进首次引导，设置里也没有这一行。第一次开着麦克风开始录制时（倒计时之后）出现系统授权对话框，用途说明为“xPaste 录屏时录下麦克风的声音”。拒绝、之前已关掉或 60 秒内没有回答时，本次录屏不录麦克风、照常录制，系统通知“麦克风权限未开启，本次录屏没有麦克风声音”；要恢复，到“系统设置 › 隐私与安全性 › 麦克风”里打开 xPaste。

### M20 动效（P1；“减少动态效果”适配为 P0）

**原则**

1. 内容永远即时可用，动效只负责说明“发生了什么、去了哪里”。
2. 键盘触发的高频操作不加或只加极短的动效；按住方向键连续移动时关闭过渡。
3. 系统开启“减少动态效果”时，全部动效降为即时切换：macOS 读取“减弱动态效果”设置，Windows 读取“显示动画效果”设置（P0）。
4. 动效只改变位移、缩放、透明度和少量模糊，不改变布局尺寸（行高展开 / 收起除外；频谱概览条窗框的位置与宽度也是例外：8 px 高，只在程序触发的换窗时过渡）。

**曲线**

| 名称 | 值 | 用途 |
| --- | --- | --- |
| enter | `cubic-bezier(0.22, 1, 0.36, 1)` | 进入、展开 |
| move | `cubic-bezier(0.25, 1, 0.5, 1)` | 位移、滑动 |
| spring | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 带回弹的落位 |

### M22 图片文字识别（P1）

图片记录在本机识别图中的文字，用于搜索（M05）和预览（M08）。阶段 10 实现。

**规则**

1. 识别使用操作系统自带的离线引擎：macOS 为 Vision，Windows 为 Windows.Media.Ocr（能识别哪些语言取决于系统已安装的 OCR 语言包）。不联网、不上传，不增加安装包体积、不带模型文件。
2. 处理图片记录和文件列表里含图片文件的文件记录（如一批图片，或图片与文档混在一起）：截图等位图识别保存在数据目录里的 PNG；文件引用识别其中仍存在的图片文件，最多 10 个，文字按文件顺序用换行拼接；多张都没有文字时，状态取最有信息量的一个：识别失败 > 本机不支持 > 已跳过 > 无文字（解不开的格式记为识别失败）。不识别视频帧、PDF 等其他类型；不含图片的文件记录没有识别状态。
3. 识别在后台进行，不在记录与唤起的路径上：新复制的图片在缩略图生成后识别，排在历史图片之前；再次复制同一张已识别的图片不重复识别。识别在低优先级线程上进行。面板可见期间暂停历史图片补识别（规则 8；进行中的那一张做完即停），面板隐藏后继续；新复制的图片与预览里点“重新识别”的图片不受面板影响，立即识别。
4. 每张图片有一个识别状态：待识别、有文字、无文字、识别失败、已跳过、本机不支持。识别结果为空或置信度均值低于 0.3 时记为无文字。
5. 有文字时，识别文字并入搜索范围（M05 规则 2，不区分大小写的子串匹配）；原文另存一份，供预览显示和复制。
6. 文件大于 20 MB 或长边大于 8000 px 的图片不识别，记为“已跳过”；识别前把长边缩到 2000 px 以内。单张超过 10 秒只记日志（软超时），慢但成功的结果照常记录。
7. 识别失败不自动重试；预览里对“识别失败”“已跳过”的图片提供“重新识别”（M08 补充规则 4）。
8. 历史图片补识别：开着“为已有图片补识别”时，应用启动 30 秒后把待识别和“已跳过”的历史图片（引擎可用时还包括上次记为“本机不支持”的）按复制时间从新到旧排队，每识别一张至少间隔 500 ms；“识别失败”的不在其中。设置页显示进度“已处理 a / b”。中途关掉补识别时，剩下的历史图片原样保留，重新打开后继续；打开开关时立即开始，不等 30 秒。
9. 关闭“识别图片中的文字”：队列里还没识别的图片记为“已跳过”，已识别的文字保留（仍可搜到）；之后新复制的图片同样记为“已跳过”。重新打开后，补识别会处理“已跳过”的图片，也可以逐张点“重新识别”。
10. 本机没有可用的识别引擎（如 Windows 没有任何 OCR 语言包）：启动时探测一次，图片记为“本机不支持”，设置页给出提示（M15）；不弹窗、不反复重试，其他功能不受影响。
11. 隐私：识别文字只存在本机数据目录，随记录删除、随“清空历史”清除。日志只记记录 id、状态、耗时与计数（如 `ocr id=N state=K ms=T`、`ocr 回填 N 张`、`ocr 已关闭，跳过 N 张`、`ocr id=N 失败 decode`），不写识别文字与文件路径。
12. 性能〔建议值〕：记录延迟与唤起指标不变（5.1）；单张 1500 px 截图识别 ≤ 1.5 秒。每个进程第一次识别要加载系统模型，macOS 上约 8 秒（开发构建实测 12.9 秒），之后每张为百毫秒级。

**验收标准**

| AC-M22-01 | 截图一段含“季度预算”字样的文字后唤起，搜索“预算” | 面板打开着也照常识别：1–2 秒内该截图出现在结果里（已在搜索时结果随识别自动刷新），行内显示命中片段（应用启动后第一次识别除外，见规则 12） |

### M23 截图与贴图（P1）

按截图快捷键冻结屏幕，框选区域或窗口，标注后复制、保存、识别文字，或者把截图钉在屏幕上（贴图）。截图复制后按普通图片进入历史，缩略图、文字识别（M22）与搜索照常生效。阶段 12 实现，见[截图与录屏设计](specs/2026-10-28-截图与录屏-设计.md)，交互以其中的原型为准；录屏见 M24。

**规则**

1. 触发：截图快捷键（M15，默认 `Alt + Shift + A`，可不启用；升级前唤起快捷键已是这组时截图快捷键为不启用，在设置里另设）全局生效。按下时冻结所有显示器的当前画面，每块屏一张，下拉菜单、悬停提示都在其中；然后在每块屏上显示全屏遮罩，背景为冻结画面。面板开着时先隐藏面板再冻结。
   - 遮罩与贴图都不激活 xPaste，也不带出面板；截图前的前台应用保持前台，截图结束后立刻打字，字进入原来的应用。Windows 上点贴图会让它成为前台，此时按截图快捷键或唤起面板，截图结束交还键盘、面板回车粘贴的目标都是点贴图之前的那个应用。
   - 遮罩已全部上屏后再按一次截图快捷键退出截图，同 Esc 退出（识别文字期间也一样，结果丢弃）。冻结中、遮罩还没全部上屏或动作完成后的提示条期间再按不响应，不开第二次截图。上一次截图 3 秒内没有全部上屏时（如遮罩页面出错），或者已上屏的遮罩不在了（被隐藏或关闭），再按快捷键撤下旧遮罩、重新开始。macOS 上遮罩页面的进程意外退出时，本次截图直接结束，页面重新加载，下次截图照常。
   - 遮罩全部上屏后，遮罩页面每秒向后端报一次平安；3 秒收不到（页面卡死、出错或进程退出）时自动撤下遮罩、交还键盘、释放冻结画面，并重新加载遮罩页面，遮罩不会一直盖在最上层挡住整台电脑，下次截图照常。动作完成后的提示条期间遮罩已鼠标穿透、交还键盘，不受这条影响。
   - 设置或确认对话框打开且面板可见时，按截图快捷键不开始截图：面板有焦点时交给录制框（M15 交互规则 3），面板失焦时只把面板拉回焦点，对话框与未保存的修改保留（M15 交互规则 4）。
2. 权限：macOS 没有屏幕录制权限时不显示遮罩，唤起面板并弹出授权确认框（M18 规则 4）。
3. 选区前：
   - 鼠标移动时吸附光标下的窗口，高亮窗口边框（不含阴影）。可吸附的窗口包括普通应用窗口和贴图，不包括遮罩自己；窗口列表不读取窗口标题。
   - 光标旁显示放大镜（光标周围 15 × 15 个像素放大约 8 倍）和光标位置的物理像素坐标；左下角显示操作提示（附录）。
   - 单击选中吸附的窗口，拖动框出矩形选区，F 选中整块屏。尺寸标签显示物理像素。
4. 多显示器：选区只能落在一块屏内，不能跨屏。光标所在的屏显示吸附、十字线和放大镜，其他屏只显示蒙层；在一块屏上选出选区后，其他屏放弃各自的选区；某块屏正在识别文字时，其他屏不能框选。不同缩放比例的屏上，吸附框按各屏的缩放换算，导出尺寸按该屏的物理像素。
5. 选区后：拖动 8 个手柄调整大小，拖动选区内部移动；方向键移动 1 px，Shift + 方向键调整大小。工具栏显示在选区下方，放不下时在上方或移进选区内。
6. 标注：
   - 工具 1–7 依次为矩形、椭圆、箭头、画笔、马赛克、文字、序号，按工具栏按钮或数字键选择，再按一次取消。
   - 颜色 6 种：红 `#FF3B47`、橙 `#FF9F1A`、绿 `#22C55E`、蓝 `#0EA5E9`、紫 `#8B5CF6`、白 `#FFFFFF`。粗细 3 档：线宽 2 / 4 / 7，字号 14 / 20 / 28，序号半径 11 / 14 / 18，马赛克笔宽 14 / 24 / 40；马赛克块为 10 逻辑像素。
   - 按住 Shift 时，矩形约束为正方形、椭圆为正圆、箭头为 45° 的倍数。
   - 文字标注：单击放置输入框，点别处或按 Esc 完成；输入期间遮罩的单键键位不生效。
   - `Mod + Z` 撤销、`Shift + Mod + Z` 重做。
7. 动作：一次截图只做一个动作。导出时选区按该屏物理像素与标注合成 PNG，Retina 屏为 2 倍尺寸。
   - 复制（回车、双击选区或工具栏“复制”）：PNG 按普通写入写进剪切板，由剪切板监听像其他截图一样入库（M01：暂停记录、不记录的应用、大小上限照常生效），自动标题“截图 YYYY-MM-DD HH.MM.png”（本地时间），随后生成缩略图并识别文字（M22）。
   - 保存（`Mod + S`）：存到截图文件夹（M15，不存在时创建），文件名与自动标题相同，重名依次加 ` 2`、` 3`，不覆盖已有文件。“保存截图时同时复制”开着时同时按复制处理；文件已保存而复制失败时，仍算保存成功。
   - 识别文字（O）：识别选区里的文字，复制为纯文本，按普通写入写进剪切板，由剪切板监听作为一条文本记录入库（M01 照常生效；与预览里只复制、不产生记录的“复制文字”不同，M08 补充规则 4）。交给系统识别前长边缩到 8000 px 以内（历史图片为 2000 px，M22 规则 6），整屏截图里的小字不会因缩小而丢失；选区图片不写入磁盘。识别期间工具栏处显示“正在识别文字…”，Esc 仍可退出，退出后结果丢弃。进程里第一次识别要加载系统模型（M22 规则 12）：每个进程第一次按截图快捷键时在后台预加载（只识别一张内存里生成的白图，不碰屏幕像素；启动时不做），预加载完成后第一次按 O 不再等模型加载；预加载还没完成时按 O 要等多久，待真机验收确认。
   - 贴图（P）：选区原地变成贴图（规则 9），不写剪切板。
   - 动作成功后遮罩淡出（160 ms），左下角提示条显示结果（附录），1.6 秒后截图结束；失败时回到选区，提示条显示原因，可以重试。
8. 退出：Esc、工具栏“退出”与再按一次截图快捷键（规则 1）直接退出，有选区也不先取消选区；右键时有选区先取消选区，没有选区退出截图。文字标注输入期间 Esc 只完成输入（规则 5）。遮罩窗口不能被关掉：Windows 上对遮罩按 Alt + F4 等同退出截图。上一次截图迟到的退出（提示条结束、淡出计时）不影响已经开始的新一次截图。
9. 贴图：
   - 每张贴图一个无边框窗口：6 px 圆角加系统窗口阴影，在普通窗口之上、遮罩之下，可以同时钉多张，之后的截图能截进去并吸附。刚钉上时的类型色描边在 240 ms 内退成细线；悬停或获得焦点时显示类型色描边。
   - 拖动：按下后移动超过 3 px 才交给系统拖动。松开鼠标后，贴图出了屏的，拉回所在显示器的工作区内：左右与底边至少留 40 px，顶边不超出。
   - 滚轮：以光标为锚缩放，范围 20%–400%，每格 ×1.1，接近 100% 时吸附到 100%。鼠标滚一格算一格；触控板按滚动距离累计，每 50 px 一格。缩放时右上角显示百分比，900 ms 后淡出。窗口每边不超过 16384 物理像素：放大的上限取 400% 与这个限制中较小的一个（如 5K 屏上的整屏贴图约 320%），到上限后再放大不变化，贴图也不移动。
   - 双击关闭（淡出 120 ms），Esc 关闭（键盘触发，即时）。
   - 右键弹出系统菜单：复制（`Mod + C`，进入历史）、保存（`Mod + S`，规则同截图的保存）、恢复原始大小（`Mod + 0`，左上角不动，只在缩放过时出现）、关闭（Esc）。复制、保存的结果显示在贴图右上角的小标签里 900 ms（附录），不弹提示条，也不显示文件名。
   - 复制与保存始终输出原图（物理像素），与当前缩放无关。
   - 只在本次运行内有效：退出 xPaste 时全部关闭，启动时清空数据目录下的 `pins/`。
10. 外观：选区框、手柄与吸附高亮用图片类型色（M16），蒙层为 `rgb(0 0 0 / .46)`，与主题无关；工具栏、标签、提示条和贴图的小标签随 xPaste 的外观设置（M16）。动效按 M20：键盘触发（数字键选工具、F）时工具栏不浮入，“减少动态效果”时全部即时。
11. 隐私：截图全部在本机处理。冻结画面在截图结束时释放，遮罩隐藏后不保留屏幕像素。日志只记显示器个数、尺寸、字节数、字数、耗时和贴图序号（如 `shot 预建遮罩 N 个`、`shot 冻结 N 屏 Tms`、`shot 上屏 Tms`），不写文件路径、文件名、窗口标题与识别文字。
12. 性能〔建议值〕：按键到遮罩上屏 ≤ 300 ms，截图功能不影响面板唤起指标（5.1）。
    - 启动后为每块屏预建隐藏的遮罩，显示器变多时补建。启动时不预先冻结屏幕（没有用户操作时不截屏），所以进程里第一次截图的冻结约 135 ms，之后更快。
    - macOS 每块 2880 × 1800 的屏冻结约 55–78 ms（含转换到 sRGB）。
    - 开着 `XPASTE_TIMING` 时记 `shot 冻结 N 屏 Tms`、`shot 上屏 Tms`。
    - 第一次截图时后台预加载识别模型（规则 7），降低线程优先级，不占上屏时间；记 `shot 预加载识别模型 Tms`（macOS 约 8 秒）。

### M24 录屏（P1，macOS）

按录屏快捷键，用截图的遮罩选出窗口、区域或整块屏，倒计时 3 秒后录成 MP4，可以带系统声音和麦克风。录制中选区四角有闪烁的直角，菜单栏显示计时；再按快捷键或点菜单“停止录制”结束。视频存进录屏文件夹，并按设置写进剪切板，作为视频记录进入历史。只在 macOS 13 及以上提供，Windows 不录屏（第 6 章）。阶段 13 实现，见[截图与录屏设计](specs/2026-10-28-截图与录屏-设计.md) §4.6 与第 8 节“阶段 13”，交互以其中的原型为准。

**规则**

1. 触发：录屏快捷键（M15，默认 `Alt + Shift + R`，显示 `⌥ + Shift + R`，可不启用）全局生效。按下时的处理看当前状态：

   | 状态 | 按录屏快捷键 | 按截图快捷键 |
   | --- | --- | --- |
   | 录制中（含倒计时结束到开始录制之间） | 停止录制（规则 8） | 不截图，见规则 10 |
   | 停止录制、写文件期间 | 不响应 | 照常截图 |
   | 设置或确认对话框开着且面板可见 | 同截图快捷键：面板有焦点时交给录制框（M15 交互规则 3），失焦时只把面板拉回焦点 | 同左（M23 规则 1） |
   | 截图或录屏遮罩已全部上屏（含倒计时） | 退出遮罩，同 Esc | 同左 |
   | 冻结中、遮罩还没全部上屏 | 不响应 | 同左 |
   | 其他 | 冻结屏幕，显示录屏遮罩（同 M23 规则 1） | 开始截图 |

   任何时候都不会同时有两次录制，也不会重复停止。遮罩卡住时的恢复（3 秒没上屏、遮罩不在了、页面无响应）同 M23 规则 1。
2. 权限：没有屏幕录制权限时不显示遮罩，唤起面板并弹出确认框“录屏需要屏幕录制权限”（M18 规则 4）。麦克风权限见规则 6 与 M18 规则 5。
3. 选区：同 M23 规则 3–5（吸附窗口、单击选中窗口、拖动框选、F 全屏、选区只在一块屏内、手柄与方向键调整）。区别：
   - 左下角提示前多一项“选择录制区域”（附录）；选区框、手柄与放大镜用视频类型色（M16），尺寸标签为录出视频的像素（按设置“录屏清晰度”换算，同规则 6），后面附设置的帧率（“· 30 fps”或“· 60 fps”）。
   - 没有标注工具与截图动作：1–7、O、P、`Mod + S`、`Mod + Z` 不响应。
   - Esc、工具栏“取消”与再按快捷键直接退出；右键有选区先取消选区，没有选区退出（同 M23 规则 8）。
4. 工具栏（选区下方，放不下时同 M23 规则 5）：系统声音开关、麦克风开关、“取消”、“开始录制 ↩”。
   - 两个开关的初值取设置“录制系统声音”“录制麦克风”（M15）。在遮罩上改了，开始录制时写回设置，下次录屏沿用；面板手里的设置随之更新，之后保存设置或切换界面状态不会把它改回去。退出遮罩不写回。
   - 麦克风只在 macOS 15 及以上可用：macOS 13–14 上开关不可用，悬停提示“麦克风需要 macOS 15”。
5. 倒计时：回车、双击选区或点“开始录制”后，选区中央显示 3 秒倒计时（视频类型色圆环，数字 3、2、1，下方“按 Esc 取消”）。
   - 倒计时期间工具栏、手柄与尺寸标签隐藏，其他按键与鼠标按下都不响应。
   - Esc 或右键直接退出录屏，不回到选区（与规则 3 的 Esc 一致）。
   - 数到 0 时遮罩淡出、开始录制。在遮罩撤下前就没能开始时回到选区，提示条显示“录屏没有开始”；遮罩撤下后才失败的，见规则 9。
   - “减少动态效果”时圆环不走，数字照常倒数。
6. 录制：
   - 遮罩撤下之后才开始录，遮罩不进视频。录的是选区所在显示器上的选区范围，带鼠标指针；贴图、面板等 xPaste 的其他窗口照常录进去，只排除录制边框（规则 7）。
   - 视频为 H.264 的 MP4，帧率按设置“录屏帧率”（30 或 60 fps，默认 30）；画面静止时帧数会少于此（见下文）。
   - 输出像素按设置“录屏清晰度”（M15，默认“标准”）：“高”为选区的逻辑尺寸 × 该屏缩放（Retina 屏为 2 倍）；“标准”与“小文件”为选区的逻辑尺寸。三档都是长边超过 3840 时等比缩小，宽高向下取偶数（5K 屏全屏：高 3840 × 2160，标准 2560 × 1440）。
   - 码率：“高”与“标准”用编码器默认码率；“小文件”指定平均码率 = 宽 × 高 × 帧率 × 0.05 bps，不低于 500 kbps（1440 × 900、30 fps 约 1.94 Mbps）。
   - 声音为 AAC，48 kHz、双声道、128 kbps。系统声音与麦克风都开时，MP4 里是两条音轨（系统声音在前），不混音。
   - 开着麦克风、还没决定过麦克风权限时，倒计时结束后先出现系统授权对话框（M18 规则 5），60 秒没有回答按没有权限处理。没有麦克风权限时本次不录麦克风，系统通知“麦克风权限未开启，本次录屏没有麦克风声音”，录制照常。
   - 画面静止时没有新帧，视频照样延续到停止的时刻。
7. 录制中：
   - 选区四角各显示一个视频类型色的直角（臂长 22 px、线宽 3 px，外加辉光），画在选区外 3 px 处，不画整圈边线；录制中四个角每秒一闪（不透明度 1 → 0.25 → 1），标出正在录的区域；“减少动态效果”打开时不闪、常亮。开始与结束时淡入淡出各 200 ms。直角所在的透明窗口铺满被录的那块屏，鼠标穿透、不抢焦点，被录制排除，不出现在视频里。选区贴着屏幕边缘时，那一边的直角收回到屏幕边上（全屏录制时四个角在屏幕四角），这时直角落在录制范围内，靠录制排除不进视频。
   - 菜单栏图标旁显示计时 `● mm:ss`（一小时起 `● h:mm:ss`），每秒更新；菜单第一项为“停止录制（<录屏快捷键>）”（M17 规则 5）。
8. 停止：点菜单“停止录制”、再按录屏快捷键，或退出 xPaste。
   - 退出 xPaste 时先停止并把文件写完、按设置写进剪切板，约 1 秒后再退出，视频可以正常打开，也来得及作为记录入库。退出最多推迟 45 秒等停止完成；推迟期间再退出一次则立即退出，文件可能没写完。
   - 倒计时结束、录制还没真正开始时按停止：录制开始后立即停止；还没开始录就被停止或退出时，不开始录制，也不留文件。
   - 停止后边框淡出，菜单栏的计时与“停止录制”一起移除。
9. 结果，用系统通知告知（标题“xPaste”，正文见附录）：
   - 文件存到录屏文件夹（M15，默认 `~/Movies/xPaste`，不存在时创建），文件名 `录屏 YYYY-MM-DD HH.MM.mp4`（本地时间），重名依次加 ` 2`、` 3`，不覆盖已有文件。
   - “录完复制到剪切板”开着时，把文件引用按普通写入写进剪切板，由剪切板监听作为视频记录入库（M01 规则 5 的例外；暂停记录、不记录的应用照常生效），封面与时长照常生成（M08）。通知“录屏已保存并复制 · mm:ss”；关着或写剪切板失败时为“录屏已保存 · mm:ss”。
   - 一帧画面都没录进去（倒计时后马上停止）：不留文件，通知“录屏太短，没有保存”。
   - 录制被系统中断（显示器断开、屏幕录制权限被撤销等）：1 秒内按停止处理，保存已录到的部分，通知“录屏中断，已保存录到的部分 · mm:ss”；一帧画面都没录到时不留文件，通知“录屏中断，没有录到画面”。
   - 开始录制失败（含建不了录屏文件夹）或写文件失败（如磁盘满，或停止后 30 秒内没写完）：不留下坏文件，边框撤下，通知“录屏失败”。系统开始采集 10 秒没有回应时按开始失败处理，并让系统停止采集（菜单栏的系统录屏指示随之消失）；停止采集 10 秒没有回应时不再等，照常写完文件。
10. 录制中按截图快捷键不开始截图（截图遮罩会被录进视频），系统通知“正在录屏，停止录制后再截图”；对话框开着且面板可见时仍按 M15 交互规则 3、4 处理。停止录制、写文件期间按截图快捷键照常截图。
11. 隐私：录屏全部在本机处理。日志只记显示器序号、选区尺寸、清晰度、帧率、声音开关、时长毫秒数与字节数（如 `rec 开始 屏 0 800x600 清晰度=Standard 帧率=30 系统声音=false 麦克风=false`、`rec 结束 Tms N 字节`、`rec 太短未保存`），不写文件路径、文件名与窗口标题。
12. 平台：只在 macOS 13 及以上。Windows 上不注册、不校验录屏快捷键（`Alt + Shift + R` 可以给唤起或截图用），设置里不显示录屏几行（M15）。

## 5. 非功能需求

### 5.1 性能〔均为建议值〕

| 指标 | 目标 |
| --- | --- |
| 冷启动到开始记录 | ≤ 2 秒 |
| 唤起面板到可输入 | ≤ 100 ms |
| 复制到出现在历史中 | ≤ 1 秒 |
| 搜索更新（5000 条） | ≤ 50 ms |
| 后台空闲 CPU | < 1% |
| 后台常驻内存 | ≤ 150 MB |
| 按截图快捷键到遮罩上屏（M23） | ≤ 300 ms |

### 5.2 隐私与安全

1. 剪切板数据只存在本机，不上传、不同步。
2. 除检查更新外不发起任何网络请求〔待确认，见 Q6〕；不收集使用统计。
3. 日志中不得写入剪切板内容。
4. 卸载时询问是否同时删除历史数据。Windows 卸载程序提供“删除应用程序数据”勾选项；macOS 以拖入废纸篓卸载，无法询问，删除数据的步骤见 README。

### 5.3 可靠性

1. 读取剪切板失败（被其他程序占用等）时跳过本次，不影响后续记录。
2. 快捷键注册失败时，通过系统通知告诉用户并引导到设置修改；唤起快捷键失败时托盘菜单第一项也改为“更换唤起快捷键…”。
3. 应用崩溃后自动恢复（开机启动项保持）；已写入数据不丢失。

### 5.4 兼容性

1. 支持多显示器、不同缩放比例（100%–200%），文字和图标清晰。
2. 支持 macOS 全屏空间、Windows 虚拟桌面。
3. 支持系统深浅色、系统强调色不影响 xPaste 配色。

### 5.5 安装、更新与卸载

1. macOS：签名并公证的 `.dmg`。
2. Windows：签名的安装包（`.exe` 或 `.msix`），支持当前用户安装（不需要管理员权限）。
3. 自动更新〔待确认〕。
4. 本期为未签名安装包，签名与公证在证书到位后进行（步骤见 README）。

### 5.6 文案与语言

1. 首版仅简体中文；日期、时间、数字按系统区域格式化。
2. 术语统一：记录、置顶、常用、复制、粘贴、来源应用（见第 2 章）。
3. 按钮写明动作结果（“保存设置”“清除搜索与筛选”）；提示条与触发它的按钮用同一个动词（“删除” → “已删除”）。
4. 错误提示说明发生了什么、怎么解决，不使用“出错了”之类的模糊说法。
