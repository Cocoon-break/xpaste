合并粘贴与片段导出导入原型

剩下的两项功能。上半页是“连续粘贴多条”，做成合并粘贴：选几条文字，按一次 Enter，按选中的先后顺序用换行连成一段粘贴出去。下半页是设置里导出、导入片段的两个按钮。

主题 面板

一、合并粘贴

现在只有“片段”分类里能多选，而且只能批量删除。改成所有分类都能多选；选中的行不打勾，改成显示粘贴顺序的序号。

  1. 按住 ⌘（Windows Ctrl）点几行：行上出现序号 1、2、3，就是粘贴出去的先后顺序；再点一次取消这一行，后面的序号往前补。
  2. 也可以按住 Shift 按 ↑↓ 连续选。
  3. 右边预览换成“已选 N 条”，按顺序列出内容。按 Enter 或点“合并粘贴”：各条之间一个换行，作为纯文本粘贴一次。
  4. 选中的里面有图片、文件时不能合并粘贴，按钮变灰并说明原因；删除照常可用。
  5. Esc、不带修饰键点一行、不带 Shift 按方向键，都退出多选（和现在片段多选一样）。

二、导出、导入片段

设置“记录”标签里，“片段”一行下面多一行“片段备份”。只导出文字类的片段（文本、代码、链接），存成一个 JSON 文件；图片、文件片段依赖本机的文件，不导出。
