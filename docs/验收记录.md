## 缺陷修复：macOS 录制 ⌃ Z 被记成 ⌘ Z（dev 直接开发）

## 启动就绪门槛与首次唤起即时（dev 直接开发，无阶段编号）

用户反馈：启动后第一次唤起先空白、过一会列表才出现。原因两个：启动后 1–3 s 网页（WKWebView 冷启动 + 脚本加载）尚未就绪，快捷键却在 0.6 s 就生效，这时唤起会先上屏空面板；以及原型的首次编排把列表压到 260 ms 后逐行浮现，720 ms 面板入场，看起来像“先空白再加载”。实测 dev 版时序（临时埋点，未提交）：进程起点 → setup 0.57 s → 网页开始加载 0.96 s → 订阅完成 2.0 s → bootstrap 往返 5 ms → 首次渲染 2.07 s；启动后首次唤起的网页内耗时与之后相同（本机日志 42–48 ms）。
