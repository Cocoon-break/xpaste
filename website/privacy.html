隐私说明

更新于 2026 年 11 月 13 日。xPaste 的隐私原则只有一条：你的剪切板历史只存在你的电脑上。

应用收集什么

不收集你的剪切板内容。xPaste 没有账号、没有云同步、没有使用统计。唯一会把内容发到网络上的是你手动发起的翻译；用授权码激活了 Pro 的话，应用还会向授权服务发送核对授权所需的几项信息，不含任何内容。两者都在下面单独说明。

另外，应用每天向 GitHub 查一次有没有新版本，请求里只有版本号，不带任何内容和标识；可以在设置“通用”里关掉“自动检查更新”。

  • 历史记录存在本机：macOS 在 ~/Library/Application Support/xPaste/，Windows 在 %APPDATA%\xPaste\。
  • 图片文字识别用系统自带的离线识别（macOS Vision、Windows.Media.Ocr），不联网、不上传。
  • 截图、贴图和录屏全部在本机处理；截图冻结的屏幕画面在截图结束时释放，不保留。
  • 来自密码管理器或被系统标记为敏感的内容默认不记录。
  • 日志里从不出现剪切板内容、标题、文件路径和搜索词。

翻译

  • 只在你按翻译时（面板里的“翻译”、截图里按 T、翻译快捷键、翻译卡片上的“翻译”与“换用…”、设置里的“测试翻译”）发送要翻译的那一段文字。复制、选中、唤起、搜索都不会发送任何内容。
  • 用 macOS 26 自带的系统翻译时在本机完成，不联网。
  • 用 AI 翻译时发到你自己在设置里填的 OpenAI 兼容接口，内容如何处理由那个服务决定；接本机的 Ollama 等服务时不出本机。请求按系统代理设置发出，可能经过你在系统里设置的代理。
  • 发出去的只有那段文字，不带别的记录、来源应用名和文件路径。来自密码管理器或被标记为敏感的内容不翻译。
  • API Key 只保存在本机的设置里；日志里不写原文、译文、API Key 和接口地址。

Pro 授权

  • 没有授权码的用户，应用不向授权服务发任何请求。
  • 用授权码激活时，以及之后每天续期一次授权时，应用把这几项发到授权服务：授权码、设备哈希（由硬件标识算出，不可逆，换不回硬件标识）、电脑名和应用版本。电脑名用来在设备列表里让你认出是哪一台。
  • 这些请求里不带任何剪切板内容、便签内容、文件路径和搜索词。

这个网站收集什么

这个网站不使用 Cookie，没有统计脚本，也不加载第三方的字体和脚本。首页上能操作的面板装的是演示数据；你在首页上复制文字时，页面会把你选中的那段文字显示在演示面板里，这只发生在你的浏览器里，不读取剪切板，也不发送到任何地方。主题选择记在浏览器的本地存储里。下载链接指向 GitHub，GitHub 会按它的政策记录访问。

在购买页下单时，网站会收下你填的邮箱（用来发授权码，以后找回授权码也靠它）和订单信息（买了什么、金额、币种、付款方式、订单状态）。付款由支付渠道处理，银行卡、支付账号这些信息不经过这个网站。没付完的订单，订单号和付款方式会记在你浏览器的本地存储里，方便刷新后接着付，付完或放弃后清掉。网站服务器会像一般网站一样记录访问日志（IP 地址、访问时间、请求路径）。

删除你的数据

在 xPaste 设置里选“清空历史…”（置顶记录会保留），或者卸载后删除上面的数据目录。数据库没有加密，靠系统账户权限保护。

联系

有疑问请到 GitHub issues 提出。剪切板历史、搜索、截图、录屏和翻译的代码全部公开，你可以自己核对上面相应的每一条；Pro 的晾衣绳便签不开源。
